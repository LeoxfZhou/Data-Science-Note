## 2. 深度学习考题提纲（Deep Learning Review Questions）
1. 机器学习（Machine Learning）和深度学习（Deep Learning）的区别是什么？重点比较人工特征工程与自动特征学习。
2. 深度学习有哪些特点？
  - 深层结构与非线性变换。
  - 自动提取特征。
  - 对大数据和大量计算能力的依赖。
  - 可解释性较差。
3. 常用深度学习模型有哪些？至少说明 CNN 面向图像、RNN 面向序列的原因与局限。
4. 深度学习有哪些主要应用场景？至少覆盖计算机视觉（Computer Vision）、自然语言处理（Natural Language Processing, NLP）、推荐系统（Recommendation System）和多模态大模型（Multimodal Large Model）。

## 3. 应用选型复习（Application Selection Review）
面对一个视觉需求，依次判断：
1. 只需要类别，还是需要位置或像素轮廓？分别对应图像分类、目标检测和图像分割。
2. 是否要求实时？是否运行在手机、摄像头或其他边缘设备？
3. 漏检、误检和延迟哪一项代价最高？
4. 训练数据量、标注粒度、类别不平衡和场景变化是否可控？
5. 是否需要生成内容，以及生成结果是否必须受姿态、边缘、深度或分割条件控制？

## 4. 损失函数与优化器复习（Loss Function and Optimizer Review）
- 互斥多分类为什么通常使用 `nn.CrossEntropyLoss()`？输入 Logits 和目标类别索引的形状要求是什么？
- `nn.BCELoss()` 与 `nn.BCEWithLogitsLoss()` 的输入约定和数值稳定性有何区别？
- MSE 与 L1 对异常值的敏感性有什么不同？
- Adam、AdamW 和带动量 SGD 的学习率、权重衰减和泛化取舍是什么？
- 为什么不能脱离数据划分、训练预算和学习率调度器，只凭优化器名称判断谁更好？
