## 1. 来源：04-C++ 指针、引用、数组与字符串（Pointers References Arrays and Strings）

### 7. 课后作业
**题目**：给你一个 `int` 型数组，请你使用指针的算术运算对数组中的元素进行操作：
1. 如果是偶数就 `+1`
1. 如果是奇数就 `+2`
**代码示例**：
```cpp
#include <iostream>
void modifyArray(int* arr, int size) {
    // 使用指针进行遍历
    int* ptr = arr;              // 指向数组起始位置
    int* endPtr = arr + size;    // 指向数组末尾（越界后第一个有效位的前沿）
    while (ptr < endPtr) {
        if (*ptr % 2 == 0) {
            *ptr += 1;  // 偶数加1
        } else {
            *ptr += 2;  // 奇数加2
        }
        ptr++;  // 指针移动到下一个元素
    }
}
int main() {
    int myArray[] = {1, 2, 3, 4, 5, 6};
    int size = sizeof(myArray) / sizeof(myArray[0]);
    std::cout << "修改前的数组: ";
    for (int i = 0; i < size; i++) {
        std::cout << myArray[i] << " ";
    }
    std::cout << std::endl;
    // 调用函数
    modifyArray(myArray, size);
    std::cout << "修改后的数组: ";
    for (int i = 0; i < size; i++) {
        std::cout << myArray[i] << " ";
    }
    std::cout << std::endl;
    return 0;
}

// 期望输出:
// 修改前的数组: 1 2 3 4 5 6 
// 修改后的数组: 3 3 5 5 7 7 
```

## 2. 来源：04-C++ 指针、引用、数组与字符串（Pointers References Arrays and Strings）

### 作业
作业是写一个文本文件，将之前你理解的关键的概念加入总结：
1. 指针是什么？和引用是什么？指针和引用之间的区别是什么？
指针是一个储存变量地址的变量，引用是变量的别名。所以引用在大部分情况下都可以直接替换成其引用的变量，改不了引用对象，除了函数传递可以用来操作实参。指针就不一样了，他只是储存那个变量的地址，可以操作变量，也可以改引用对象。

## 4. 来源：05-C++ 函数、回调与递归（Functions Callbacks and Recursion）

### 作业
**题目：** 编写一个函数，用于判断一个年份是否为闰年。
**参考实现与代码解释：**
```cpp
#include <iostream>
// 函数用于判断一个年份是否为闰年
bool isLeapYear(int year) {
    // 闰年的判断规则：
    // 1. 能被 4 整除但不能被 100 整除
    // 2. 能被 400 整除
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}
int main() {
    int year;
    std::cout << "请输入一个年份: ";
    std::cin >> year;
    if (isLeapYear(year)) {
        std::cout << year << " 年是闰年。" << std::endl;
    } else {
        std::cout << year << " 年不是闰年。" << std::endl;
    }
    return 0;
}

// 示例输入: 2000
// 期望输出:
// 请输入一个年份: 2000 年是闰年。
//
// 其他代表性输入与输出:
// 输入 2024 -> 请输入一个年份: 2024 年是闰年。
// 输入 1900 -> 请输入一个年份: 1900 年不是闰年。
```
- **核心逻辑**：`(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)` 完美实现了闰年的数学规则。
- **`main`** **函数流程**：声明 `year` 变量 $\rightarrow$ 使用 `std::cin` 读取输入 $\rightarrow$ 调用自定义的 `isLeapYear` 函数 $\rightarrow$ 通过 `if-else` 输出结果。

## 5. 来源：05-C++ 函数、回调与递归（Functions Callbacks and Recursion）

### 作业
请根据 `main` 函数中的测试代码实现 `sum`, `product`, `calculate` 三个函数：
**题目骨架与参考实现（Scaffold and Reference Implementation）:**
```cpp
#include <stdio.h>

// 计算数组元素的和。
int sum(int arr[], int len) {
  int total = 0;
  for (int i = 0; i < len; i++) {
    total += arr[i];
  }
  return total;
}

// 计算数组元素的积。初值必须为 1；若从 0 开始，任何乘积都会错误地变成 0。
int product(int arr[], int len) {
  int result = 1;
  for (int i = 0; i < len; i++) {
    result *= arr[i];
  }
  return result;
}

// 把具体聚合策略作为函数指针传入，使同一个 calculate() 可以复用遍历入口。
int calculate(int arr[], int len, int (*func)(int *, int)) {
  return func(arr, len);
}

int main() {
  int arr[] = {1, 2, 3, 4, 5};
  int len = sizeof(arr) / sizeof(arr[0]);
  // 计算数组元素的和
  int sum_result = calculate(arr, len, sum);
  printf("Sum: %d\n", sum_result);
  // 计算数组元素的积
  int product_result = calculate(arr, len, product);
  printf("Product: %d\n", product_result);
  return 0;
}

// 期望输出:
// Sum: 15
// Product: 120
```

## 6. 来源：05-C++ 函数、回调与递归（Functions Callbacks and Recursion）

### 作业
编写一个 `C++` 函数，使用递归方法计算斐波那契数列的第 `n` 项。
**斐波那契数列定义：**
- `F(0) = 0`
- `F(1) = 1`
- `F(n) = F(n-1) + F(n-2)` (当 `n >= 2` 时)
同学们要同时使用 `Python` 也一样同样逻辑的实现，我们求 `fibnacci(20)`，运行 `1000000` 次，看出 `Python` 用时和 `C++` 的用时，统计 `C++` 和 `Python` 的用时差距。

> [!important] 函数设计与性能边界（Function Design and Performance Boundaries）
> 返回动态数组裸指针会把释放责任转交调用者，容易泄漏；新代码优先返回 `std::vector<T>`、`std::array<T, N>` 或拥有所有权的智能指针。只靠返回类型不同不能构成函数重载。默认实参应在同一可见声明中只指定一次。`inline` 的核心语言意义还包括允许相同定义出现在多个翻译单元；是否真的展开调用由优化器决定。朴素递归斐波那契的时间复杂度呈指数增长，跨语言基准必须统一输入、重复次数、编译优化级别、计时范围与预热条件。
