## 第一个 C++ 程序
- **关键语法区别**：
    
    - C++ 必须有 `int main()` 主函数作为程序执行的起点。
    
    - 每条语句必须以分号 `;` 结尾。
    
    - 静态类型语言 (Static Typed Language)，变量需先声明类型。
    
- **输入与输出**：
    
    - `cout <<`：向控制台输出数据，`<<` 称为插入运算符 (Insertion Operator)。
    
    - `cin >>`：从键盘读取数据，`>>` 称为提取运算符 (Extraction Operator)。
    
```C++
\#include <iostream> // 预处理指令，引入输入输出库
using namespace std; // 使用标准命名空间，避免每次写 std::
int main() { // 主函数
    cout << "Hello, World!" << endl; // 输出内容，endl 表示换行
    return 0; // 返回 0 表示程序正常结束
}
```
## C++ 数据类型与算术运算
- **基本数据类型**：
    
    - `int` (整型, Integer)：通常 4 字节，存储整数。
    
    - `char` (字符型, Character)：通常 1 字节，存储单个字符，用单引号括起（如 `'A'`）。
    
    - `float` (单精度浮点型, Single-precision Floating-point)：4 字节，字面量加 `f` 后缀。
    
    - `double` (双精度浮点型, Double-precision Floating-point)：8 字节，精度更高，日常推荐使用。
    
    - `bool` (布尔型, Boolean)：1 字节，值为 `true` 或 `false`。
    
    - `void` (空类型)：表示没有类型/没有值。
    
- **算术运算符**：`+` (加), (减), (乘), `/` (除), `%` (取余)。
- `**sizeof**` **运算符**：**重要纠正：**`**sizeof**` **是一个运算符 (Operator)，不是函数！** 用于获取数据类型或变量所占内存大小（字节数）。
- **整数除法与取余**：
    
    - **整数除法截断 (Integer Division Truncation)**：两个整数相除，结果截断为整数，不四舍五入（如 `7 / 3` 结果为 `2`）。若需浮点结果，至少一个操作数应为浮点数（如 `7.0 / 3`）。
    
    - **取余应用**：判断整除 (`a % b == 0`)、获取个位 (`n % 10`)、判断奇偶 (`n % 2 == 0`)。
    
```C++
\#include <iostream>
using namespace std;
int main() {
    int a = 10, b = 3;
    // 算术运算与截断行为
    cout << "a / b = " << a / b << endl; // 输出 3 (整数除法截断)
    cout << "a % b = " << a % b << endl; // 输出 1 (取余数)
    // sizeof 运算符的使用
    cout << "sizeof(int) = " << sizeof(int) << " bytes" << endl; // 输出 4 bytes
    return 0;
}
```
# 流程控制与复合数据类型
## 一、流程控制语句 (Flow Control Statements)
流程控制语句用于根据条件决定代码的执行路径，或者重复执行特定的代码块。C++ 中的流程控制主要分为条件判断和循环执行两类。
### 1. 条件判断：`if` 语句
`if` 语句允许程序根据条件表达式的布尔值 (Boolean) 的真假 (`true` 或 `false`) 来决定是否执行特定的代码块。
- **基本结构**：包含 `if`、`else if` 和 `else`。其中 `else if` 可以有多个，`else` 最多只能有一个且必须放在最后。
- **比较运算符 (Comparison Operators)**：`==` (等于), `!=` (不等于), `<` (小于), `>` (大于), `<=` (小于等于), `>=` (大于等于)。
    
    - **⚠️ 易错警告**：务必区分赋值运算符 `=` 和等于运算符 `==`。
    
- **逻辑运算符 (Logical Operators)**：用于组合多个条件。
    
    - `&&` (逻辑与 AND)：所有条件都为真，结果才为真。
    
    - `||` (逻辑或 OR)：只要有一个条件为真，结果就为真。
    
    - `!` (逻辑非 NOT)：对条件取反。
    
```C++
\#include <iostream>
using namespace std;
int main() {
    char ch;
    cout << "请输入一个字符: ";
    cin >> ch;
    // 使用逻辑与 && 组合条件
    if (ch >= 'A' && ch <= 'Z') {
        cout << ch << " 是大写字母" << endl;
    } else if (ch >= 'a' && ch <= 'z') {
        cout << ch << " 是小写字母" << endl;
    } else if (ch >= '0' && ch <= '9') {
        cout << ch << " 是数字" << endl;
    } else {
        cout << ch << " 是其他字符" << endl;
    }
    return 0;
}
```
### 2. 循环语句：`while` 与 `do-while`
- `**while**` **循环**：先判断条件，再执行循环体。如果初始条件为假，循环体一次都不会执行。
- `**do-while**` **循环**：先执行一次循环体，再判断条件。因此，**无论条件真假，它至少会执行一次**。常用于菜单驱动程序或输入验证。注意 `while` 后面的分号 `;` 绝不能漏掉。
```C++
\#include <iostream>
using namespace std;
int main() {
    int score;
    // do-while 结构：至少执行一次输入和判断
    do {
        cout << "请输入成绩 (0-100): ";
        cin >> score;
        if (score < 0 || score > 100) {
            cout << "输入无效，请重新输入！" << endl;
        }
    } while (score < 0 || score > 100); // 别忘了这里的分号
    cout << "验证通过，成绩是: " << score << endl;
    return 0;
}
```
### 3. 循环语句：`for` 循环
`for` 循环提供了更结构化和紧凑的循环方式，非常适合循环次数已知的情况。
- **三个核心部分**：`for (初始化语句; 条件表达式; 递增/递减语句)`。
    
    - **初始化**：循环前仅执行一次。
    
    - **条件表达式**：每次迭代前判断。
    
    - **递增/递减**：每次迭代结束后执行。
    
```C++
\#include <iostream>
using namespace std;
int main() {
    int sum = 0;
    // 初始化; 条件; 更新
    for (int i = 1; i <= 10; i++) {
        sum += i;
    }
    cout << "1到10的和为: " << sum << endl;
    return 0;
}
```
### 4. 循环控制：`break` 与 `continue`
- `**break**`：立即退出并终止整个循环。
- `**continue**`：跳过本次迭代的剩余代码，直接进入下一次循环。
## 二、复合数据类型 (Composite Data Types)
基本数据类型（如 `int`、`double`）只能存储单个值，而复合数据类型可以组织和处理更复杂的数据集。
### 1. 数组 (Array)
数组是一种线性数据结构，用于存储一组相同类型的数据集合。它就像一排连续的储物柜。
- **核心特点**：固定大小、数据类型相同。
- **索引 / 下标 (Index)**：数组下标从 `0` 开始。大小为 `n` 的数组，合法下标范围是 `0` 到 `n-1`。
- **越界访问 (Out-of-bounds Access)**：访问超出合法范围的下标（如 `arr[5]` 访问大小为5的数组）会导致未定义行为，甚至程序崩溃。
```C++
\#include <iostream>
using namespace std;
int main() {
    // 声明并完全初始化一个整型数组
    int numbers[5] = {10, 20, 30, 40, 50};
    int sum = 0;
    // 数组经常与 for 循环搭配使用进行遍历
    for (int i = 0; i < 5; i++) {
        sum += numbers[i];
    }
    // 使用 static_cast 强制类型转换，防止整数除法截断
    double average = static_cast<double>(sum) / 5;
    cout << "数组元素的均值为: " << average << endl;
    return 0;
}
```
### 2. 字符串 (String)
在 C++ 中，处理字符和文本时有一个非常重要的标点符号规则：
- **⚠️ 核心规则**：**C++ 中单字符使用单引号包裹（如** `**'A'**`**），字符串使用双引号包裹（如** `**"Hello"**`**）。**
### A. C 风格字符串 (C-style Strings)
本质上是以空字符 `'\\0'` 结尾的字符数组 (Character Array)。
- **声明方式**：`char str[] = "hello";` （虽然只看到5个字母，但系统会自动在末尾加上 `'\\0'`，实际占用 6 个字节）。
- **缺点**：使用繁琐，容易出现内存越界错误，一般在现代 C++ 开发中尽量少用。
### B. C++ 标准库 `string` 类
C++ 提供了 `<string>` 头文件，这是现代 C++ 处理文本的首选方式。
- **优势**：自动管理内存（不需要管长度和 `\\0`）、支持直接用 `+` 拼接、提供丰富的内置函数（如 `.length()` 获取长度）。
### C. 字符串的输入方式
- `cin >> str`：遇到空格或换行就会停止读取（只能读取单个单词）。
- `getline(cin, str)`：读取包含空格的整行文本，直到遇到换行符才停止。
```C++
\#include <iostream>
\#include <string> // 必须引入 string 头文件
using namespace std;
int main() {
    string name;
    string sentence;
    // 方式一：cin >> （读取单词）
    cout << "请输入你的名字 (中间不要有空格): ";
    cin >> name;
    // 清除上一次输入残留在缓冲区的换行符，防止干扰 getline
    cin.ignore();
    // 方式二：getline() （读取整行）
    cout << "请输入一句包含空格的话: ";
    getline(cin, sentence);
    // 字符串拼接与输出
    string result = "你好, " + name + "! 你说: " + sentence;
    cout << result << endl;
    cout << "这句话的长度是: " << result.length() << " 个字符。" << endl;
    return 0;
}
```
