## 统一整理规则（Normalization Rules）

1. **取并集（Union）**：原稿是最低信息基线；Review 中已有的扩展说明按主题嵌回相邻章节。
2. **仅删完全重复（Exact Duplicate）**：参数（Parameter）、返回值（Return Value）、示例（Example）、边界条件（Edge Case）、异常（Exception）与补充注释不得因压缩篇幅而删除。
3. **专业名词（Technical Term）双语化**：中文专业名词采用“中文术语（English Term）”；库名、API、命令、文件名和代码标识符（Code Identifier）保持原写法。
4. **代码输出（Output）**：每个适用的 Python 示例下方都有期望输出；确定性且可安全运行的示例尽量写入实际控制台输出（Console Output）。
5. **副作用豁免（Side-effect Exemption）**：写文件（File Writing）、网络请求（Network Request）、数据库变更（Database Mutation）以及依赖本机路径 (Path)或用户输入的示例，只说明结果模式或豁免原因。
6. **纠错（Correction）**：修复明显语法错误 (Syntax Error)、错误 (Error)缩进和失效示例；故意展示错误 (Error)的反例必须明确标记，不能伪装成可正常执行的代码。
7. **Obsidian 兼容性（Obsidian Compatibility）**：保留 Wiki Link、YAML、代码围栏（Code Fence）、公式（Formula）和附件引用（Attachment Reference）。
