## 一、集成学习 (Ensemble Learning) 概述

- **核心思想 (Core Idea)**：将若干个学习器（分类器或回归器）组合之后产生一个新学习器，以期达到比单一模型更好的预测效果 。
    
- **弱分类器 (Weak Learner)**：分类准确率只稍微好于随机猜测的分类器（错误率 < 0.5） 。
    
- **成功关键 (Key to Success)**：保证弱分类器之间的**多样性 (Diversity)** 。集成不稳定的算法通常能够得到明显的性能提升 。
    
- **主要优势 (Main Advantages)**：
    
    - 结合多个弱分类器能得到更合理的**决策边界 (Decision Boundary)**，从而减少整体错误率 。
        
    - 对于过大或过小的数据集，可分别进行划分或使用有放回操作产生不同的**数据子集 (Data Subsets)**，分别训练分类器后再合并 。
        
    - 使用线性模型难以描述复杂划分边界时，可以训练多个模型然后进行融合 。
        
    - 方便对异构**特征集 (Feature Sets)** 分别构建分类模型再进行融合 。
        
- **常见算法 (Common Algorithms)**：主要有 Bagging、Boosting 和 Stacking 。
    

## 二、Bagging 方法与随机森林 (Random Forest)

### 1. Bagging (Bootstrap Aggregating, 自举汇聚法)

- **基本思想 (Basic Concept)**：在原始数据集上通过**有放回的随机抽样 (Bootstrap Sampling)** 重新选择出 S 个新数据集，来分别训练 S 个分类器 。
    
- **预测策略 (Prediction Strategy)**：在预测新样本时，通常使用**多数投票 (Majority Voting)** 或**求均值 (Averaging)** 的方式统计最终的分类或回归结果 。
    
- **袋外数据 (Out-of-Bag Data, OOB)**：由于是有放回的抽样，每个子集的样本量与原始数据集一致，这导致约有 1/3 (约 36.8%) 的样本数据不会出现在 Bagging 单个子模型的训练数据中 。
    

### 2. 随机森林 (Random Forest, RF)

- **基本原理 (Basic Principle)**：是在 Bagging 策略基础上进行修改后的一种算法 。首先用 Bootstrap 采样选出样本子集，在使用这些子集训练**决策树 (Decision Tree)** 的过程中，从所有属性中随机抽取 K 个待选属性，再从中选择最佳分割属性作为当前节点的划分依据，重复此过程建立 m 棵树形成森林 。最终通过投票表决决定数据分类 。
    
- **主要优点 (Pros)**：
    
    - 训练可以**并行化 (Parallelization)**，对大规模样本训练具备速度优势 。
        
    - 由于随机选择决策树划分特征，在**高维数据 (High-dimensional Data)** 下依然具备很高的训练性能 。
        
    - 可以输出各个特征的**特征重要性 (Feature Importance)** 列表 。
        
    - 模型**方差 (Variance)** 小，**泛化能力 (Generalization Ability)** 强，能够缓解**过拟合 (Overfitting)** 。
        
- **主要缺点 (Cons)**：在某些噪音较大的特征上容易陷入过拟合；取值较多的划分特征可能会对模型产生更大的影响 。
    
- **常见变种 (Variants)**：
    
    - **Extra Tree**：每个子决策树直接使用原始数据集训练（不重采样），且完全随机选择特征值进行划分，方差相对于 RF 进一步减少 。
        
    - **TRTE (Totally Random Trees Embedding)**：一种非监督的数据转化方式，将低维数据映射到高维 。
        
    - **Isolation Forest (IForest)**：用于**异常点检测 (Anomaly Detection)**，随机选择特征和划分阈值，一般构建深度较大的决策树，仅需少量数据即可运行 。
        

## 三、提升算法 (Boosting) 与 AdaBoost

### 1. Boosting (提升学习)

- **基本概念 (Basic Concept)**：一种迭代机器学习技术，每一步产生一个弱预测模型并加权累加到总模型中 。如果每一步弱模型依据损失函数的梯度方式生成，则称为**梯度提升 (Gradient Boosting)** 。常见模型有 AdaBoost 和 GBDT 。
    

### 2. AdaBoost (Adaptive Boosting)

- **算法原理 (Algorithm Principle)**：在每轮迭代中会评估训练集中每个样本的重要性 。如果某个样本被预测得越正确，则降低其**权重 (Weight)**；如果预测错误，则提高其权重 。越难区分的样本在后续迭代训练中就会变得越重要 。
    
- **强分类器构建 (Strong Classifier Construction)**：将基分类器进行线性组合作为强分类器 。给分类误差率较小的基分类器赋予较大的权值，给分类误差率大的基分类器赋予较小的权重值，最终分类器在线性组合的基础上进行 Sign 函数转换 。
    
- **优缺点 (Pros and Cons)**：
    
    - **优点**：可以处理连续值和离散值；模型**鲁棒性 (Robustness)** 较强；结构简单，解释性强 。
        
    - **缺点**：对**异常样本 (Outliers)** 敏感，异常样本可能会在迭代过程中获得过高的权重值，从而影响最终效果 。
        

## 四、梯度提升迭代决策树 (GBDT)

- **基本原理 (Basic Principle)**：GBDT 也是一种 Boosting 算法，但它要求底层必须是 **CART 回归树 (Regression Tree)** 。模型在训练时要求预测的样本损失尽可能的小 。它使用之前子树构建结果后形成的**残差 (Residual)** 作为输入数据来构建下一棵子树 。
    
- **核心构成 (Core Components)**：由 DT (回归决策树)、GB (梯度提升) 和 **衰减 (Shrinkage)** 三部分构成 。其中，利用损失函数的负梯度作为残差的近似值进行拟合 。通过给定**步长 (Learning Rate / Step)**，在构建下一棵树时使用步长乘以残差作为输入，以减少过拟合 。
    
- **损失函数 (Loss Functions)**：
    
    - **回归任务 (Regression)**：一般选择**均方差 (Mean Squared Error, MSE)** 或**绝对值损失 (Absolute Error)** 。
        
    - **分类任务 (Classification)**：一般选择**对数损失函数 (Log Loss / Deviance)** 。
        
- **优缺点 (Pros and Cons)**：
    
    - **优点**：可以处理连续值和离散值；在较少的调参情况下模型也能有不错的预测效果；模型的鲁棒性比较强 。
        
    - **缺点**：由于弱学习器之间存在关联关系，难以**并行训练 (Parallel Training)** 模型，导致模型训练速度慢 。
