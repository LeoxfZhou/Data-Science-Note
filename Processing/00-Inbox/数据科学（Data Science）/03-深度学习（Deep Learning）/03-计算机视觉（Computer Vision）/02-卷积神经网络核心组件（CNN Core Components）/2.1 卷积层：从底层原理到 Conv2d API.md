## 1. 数据输入层 (Input Layer)

在卷积神经网络中，对输入数据进行**预处理**是非常关键的步骤。

### 1.1 为什么需要预处理？

- **加快收敛**：如果输入数据的量纲或范围差异过大，会导致网络训练时收敛速度慢、耗时长。
- **平衡特征权重**：数据范围大的特征在模型中的作用可能会被无形放大，而范围小的特征作用则会被削弱。
- **契合激活函数值域**：神经网络的激活函数（如 Sigmoid）通常有特定的敏感区间（如 $(-4, 4)$），超出该区间后函数极其平缓，容易导致梯度消失。

### 1.2 常见的 3 种数据预处理方式

1. **去均值 (Zero-centering)**：将输入数据的各个维度中心化到以 0 为中心。
2. **标准化 (Normalization)**：将输入数据各个维度的幅度标准化到相同的范围。
3. **PCA / 白化 (Whitening)**：利用 PCA 进行降维并去除特征间的相关性。白化则是在 PCA 基础上对转换后的特征进行幅度标准化。

> **注意**：虽然 PCA 和白化在经典机器学习中很常用，但在**卷积神经网络（CNN）中一般不使用 PCA 和白化**，而通常仅适用**去均值和归一化 / 标准化**。

### 1.3 常用图像特征转换

在计算机视觉中，通常利用 Pillow 或 OpenCV 进行更多的图像转换操作：

- **几何变换**（缩放、旋转、翻转等）
- **颜色处理**（灰度化、色调调整等）
- **图像合成**与**图像增强**

## 2. 人脑视觉机制与卷积计算层 (CONV Layer)

### 2.1 人脑识别图片的启发

人脑在识别图像时，并非瞬间全局感知，而是通过不同的皮质层处理不同维度的局部数据（如颜色、形状、光暗），最后在更高层级将局部观察结果进行合并映射，得出整体结论。

### 2.2 卷积层的核心特征

基于人脑的视觉机理，卷积神经网络（CNN）引入了以下核心设计：

- **局部感知 (Local Perception)**：每个神经元（即卷积核 / Filter）只与输入图像的局部区域（感受野 Receptive Field）相连接，大大减少了参数量。
- **参数共享机制 (Parameter Sharing)**：在同一特征图（Feature Map）内滑动时，同一个卷积核的权重是固定的。这相当于将卷积核视为一种特定的特征提取模板。
- **滑动窗口重叠**：卷积核在滑动时通常会有重叠，以降低窗口之间的边缘不平滑特性。

### 2.3 卷积的核心概念与运算

- **维度要素**：深度 (Depth)、步长 (Stride)、填充值 (Zero-padding)。
- **多通道输入**：以 $32 \times 32 \times 3$ 的 RGB 图像为例，输入有 3 个通道。卷积核的大小也必须是 $5 \times 5 \times 3$。它与图像局部区域做矩阵内积并求和，最后加上偏置项 $b$，输出一个标量值 $w^T x + b$。
- 一个卷积核在图像上完全滑动后，会生成一个二维的 **激活图 (Activation Map / Feature Map)**。堆叠多个卷积核的输出，就能得到新维度的特征图。

## 3. 激活函数层 (Activation Function Layer)

激活层对卷积层的输出结果进行非线性映射，为网络引入非线性表达能力。

### 3.1 常见激活函数对比

|**激活函数**|**公式**|**优点**|**缺点 / 改进方案**|
|---|---|---|---|
|**Sigmoid**|$f(x) = \frac{1}{1 + e^{-x}}$|值域为 $(0, 1)$，简单直观。|容易饱和，导致梯度消失；输出非 0 中心化。|
|**Tanh**|$f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$|值域为 $(-1, 1)$，解决了 0 中心化问题。|依然存在梯度饱和与“死神经元”问题。|
|**ReLU**|$f(x) = \max(0, x)$|单侧抑制、宽阔兴奋边界、稀疏激活；梯度计算极其简单，不产生梯度消失，收敛速度远快于 Sigmoid/Tanh。|没有上限（可用变种限制，如 $\min(\max(0,x), 6)$）；神经元容易“坏死”（Dead ReLU）。_方案：设置较小的学习率_。|
|**Leaky ReLU**|$f(x) = \max(\alpha x, x)$|在 $x \le 0$ 时引入微小的线性修正斜率 $\alpha$，试图解决 ReLU 死神经元问题。|实际场景中效果并不稳定。|
|**ELU**|$f(x) = \max(\alpha(e^x-1), x)$|在 $x \le 0$ 部分使用指数进行平滑修正。|计算量稍大。|

> **应用建议**：在 CNN 中尽量不要使用 Sigmoid（若要使用，建议仅在全连接层尾部使用）。首选 **ReLU**，如果训练中 ReLU 出现大面积失效导致坏死，再考虑使用 **Leaky ReLU** 或 **ELU**。

## 4. 神经网络中的各类归一化层 (Normalization Layers)

在深度网络训练中，由于参数更新，中间层的数据分布会持续发生偏移（称为 **Internal Covariate Shift**）。引入归一化层可以使数据恢复较好的分布，从而稳定网络学习，加速收敛。

### 4.1 Batch Normalization (批归一化 - BN)

- **原理**：针对一个 Mini-batch 内的所有样本，对每一个神经元（或 CNN 的每一个 Feature Map）求均值和方差进行标准化。
- **计算步骤**（训练阶段）：
    
    1. 求解当前批次均值：$\mu_B = \frac{1}{m}\sum_{i=1}^{m} x_i$
    2. 求解当前批次方差：$\sigma_B^2 = \frac{1}{m}\sum_{i=1}^{m} (x_i - \mu_B)^2$
    3. 标准化：$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$
    4. 尺度变换与平移（核心）：$y_i = \gamma \hat{x}_i + \beta$（引入可学习参数 $\gamma$ 与 $\beta$，防止标准化破坏网络的非线性表达能力）。
        
- **预测阶段**：由于预测时样本可能只有一个，因此无法计算 batch 的均值和方差。预测时使用的是**整个训练阶段记录下来的均值和方差的期望值**（通常利用滑动平均法计算）。
- **在 CNN 中的应用**：BN 在 CNN 中是**以 Feature Map（通道）为单位**的，即一个 Batch 中一个 Channel 的所有特征图共享同一对 $\gamma$ 和 $\beta$，能极大地减少参数量。
- **优缺点**：
    - _优点_：梯度流动顺畅（防梯度弥散/爆炸）；允许更大的学习率；对初始化不敏感；具一定正则化效果。
    - _缺点_：对 Batch Size 敏感（过小时均值方差不准，建议 $\ge 16$）；不适合不定长网络（如 RNN）。

### 4.2 Layer Normalization (层归一化 - LN)

- **原理**：针对**单一样本**，计算当前样本同层所有神经元（特征通道）的均值和方差并归一化。
- **特点**：不受批次大小（Batch Size）的影响。在 **RNN 上效果非常明显**，但在 CNN 上的表现通常不及 BN。

### 4.3 Instance Normalization (实例归一化 - IN)

- **原理**：仅对**单个样本的单个 Feature Map (H $\times$ W)** 独立进行归一化。
- **应用场景**：常用于**图像风格化生成**。因为生成结果高度依赖单个图像实例的独立风格，不适合跨样本（Batch）做归一化。

### 4.4 Group Normalization (组归一化 - GN)

- **原理**：介于 LN 和 IN 之间。将通道（Channel）方向划分为不同的组（Group），在每个组内计算均值和方差（即对 $(C/G) \times H \times W$ 的区域进行归一化）。
- **优点**：完美解决了 BN 在 **小 Batch Size 下效果极差** 的问题。其计算完全独立于 Batch Size，在极小批次下精度依旧非常稳定。

### 4.5 Switchable Normalization (自适应归一化 - SN)

- **原理**：前述 BN、LN、IN、GN 均是人工设计的硬性归一化，无法通用。SN 通过引入学习权重，自适应地将 BN、LN、IN 的均值与方差进行加权混合：
    
    $$\hat{h} = \gamma \frac{h - \sum_{k} w_k \mu_k}{\sqrt{\sum_{k} w'_k \sigma_k^2 + \epsilon}} + \beta$$
    
- **优点**：自适应确定最佳归一化操作，业务耦合度低，通用性极强。

## 5. 卷积神经网络可视化理解

卷积神经网络并不是一个黑盒，其层级结构具有鲜明的特征提取规律：

- **浅层卷积层 (Conv 1 - Conv 2)**：提取的是非常基础的局部特征，如边缘、线条、颜色斑块。
- **深层卷积层 (Conv 3 - Conv 5)**：随着感受野的变大和特征的叠加，深层网络提取的是高阶的、丰富的、富含抽象语义的特征（如人脸轮廓、车辆形状等）。

## 6. 卷积神经网络的优缺点

### 6.1 优点

- **高效降维与特征提取**：通过“局部感知”和“参数共享”，对处理高维图像数据毫无压力。
- **端到端学习**：无需人工手动设计或选择特征属性，网络能通过反向传播自动学习特征权重。
- **表达能力强**：深层网络提取的层次特征表达效果极其优异。

### 6.2 缺点

- **调参难度大**：需要大量的超参数微调，需要庞大的样本量支持，通常迭代次数多，对 GPU 算力依赖度高。
- **可解释性（物理含义）差**：作为“黑盒”模型，很难用物理学或直观逻辑去精确解释中间每层特征图的具体含义。

## 7. 参数初始化 (Parameter Initialization)

w 和 b 的初始化取值会直接影响模型的收敛速度和精度。

### 7.1 权重的初始化

- **错误方式 - 全部设为 0**：如果权重全部初始化为 0，反向传播时每个神经元会得到完全相同的梯度，导致权重无法差异化更新，网络无法学习。
- **推荐方式**：
    - **小随机高斯分布**：均值为 0，方差较小（例如使用 He 初始化推荐的 $2/n$，其中 $n$ 为输入权重数量）。
    - **Xavier 初始化**：服从特定的均匀分布，常用于不带 ReLU 的激活网络：
        
        $$W \sim U\left[ -\sqrt{\frac{6}{n_j + n_{j+1}}}, \sqrt{\frac{6}{n_j + n_{j+1}}} \right]$$
        
        _(其中 $n_j$ 和 $n_{j+1}$ 分别为输入和输出维度)_
        
    - **权重标准化 (Weight Standardization - WS)**：类似批归一化，在 CONV / FC 之前，对权重系数本身进行标准化操作，使模型表现更好。

### 7.2 偏置项 (Bias) 的初始化

- 一般直接初始化为 **0**。在采用 **ReLU** 激活函数的网络中，也可以考虑初始化为一个极小的正数（如 0.01），以尽量避免 ReLU 初始直接进入死区。

## 8. 正则化与 Dropout

神经网络容量（神经元、层数）越大，其空间表达能力就越强，同时也极易发生**过拟合 (Overfitting)**。

### 8.1 正则化 (Regularization)

- 通过在损失函数上添加惩罚项（如 **L1 / L2 范数**）来限制模型权重的大小，从而降低模型复杂度，抑制过拟合。

### 8.2 Dropout 机制

- **原理**：在每次训练迭代中，以一定的概率 $p$ 随机“丢弃”（不激活）部分隐藏层神经元。预测（推理）阶段则激活所有神经元进行预测。
- **为什么有效？**
    - 相当于在不同的子网络结构上训练，最后在推理时进行集成（Ensemble）。
    - 阻断了神经元之间的强共适应性，迫使网络学习更加健壮、鲁棒的独立特征。
- **反向传播中的 Inverted Dropout 代码示例**： 为了避免在推理阶段乘以概率 $p$ 进行缩放，现代深度学习框架常用 **Inverted Dropout**（在训练时除以 $p$ 进行尺度补偿）：

Python

```
# 训练阶段
p = 0.5  # 神经元保留概率
H1 = np.maximum(0, np.dot(W1, X) + b1)

# 生成 Dropout 掩码，并除以 p 进行值放大
U1 = (np.random.rand(*H1.shape) < p) / p 
H1 *= U1  # 随机丢弃部分激活值

H2 = np.maximum(0, np.dot(W2, H1) + b2)
U2 = (np.random.rand(*H2.shape) < p) / p
H2 *= U2

out = np.dot(W3, H2) + b3

# 预测阶段 (无需进行任何尺度调整，直接前向传播)
H1 = np.maximum(0, np.dot(W1, X) + b1)
H2 = np.maximum(0, np.dot(W2, H1) + b2)
out = np.dot(W3, H2) + b3
```

> **重要避坑指南**： 在**回归算法**中，L2 范数的优化难度比分类器的 Softmax 更高。如果确实需要处理回归问题：
> 
> 1. 首先考虑能否将回归转换为分类（例如：将 1~5 评分回归问题，转化为 5 分类问题）。
>     
> 2. 如果无法转化，必须使用 L2 范数时，**绝对不要在 L2 范数前使用 Dropout**，否则会导致极难优化。
