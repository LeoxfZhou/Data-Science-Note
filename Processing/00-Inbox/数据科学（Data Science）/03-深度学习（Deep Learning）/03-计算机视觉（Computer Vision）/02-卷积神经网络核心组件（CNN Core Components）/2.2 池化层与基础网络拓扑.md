## 1. 池化结构讲解 (Pooling Layer)

在卷积神经网络中，卷积层负责提取特征，而**池化层（Pooling Layer）**则负责进行**下采样（Downsampling）**。它在保留核心特征的同时，降低数据的空间维度。

### 1 为什么需要池化？

- **特征不变性 (Invariance)**：使网络对图像的微小位移、旋转和伸缩具有**平移不变性**。也就是说，某个特征稍微移动了一点，池化后的响应依然类似。
- **降维与防过拟合**：减少后续层（如全连接层）的参数量和计算量，在一定程度上缓解模型的过拟合问题。
- **扩大感受野**：经过池化后，下一层的卷积核能够覆盖更广的原始输入区域。

### 2 常见的池化类型

- **最大池化 (Max Pooling)**：在滤波窗口内选择**最大值**作为输出。
    - _特点_：能够提取图像中最强烈的纹理、边缘等显著特征。在计算机视觉中**最为常用**。
- **平均池化 (Average Pooling)**：计算滤波窗口内所有像素的**平均值**作为输出。
    - _特点_：倾向于保留背景信息，使特征图更加平滑，但可能会淡化边缘等高频细节。
- **全局平均池化 (Global Average Pooling - GAP)**：将整张特征图（$H \times W$）直接平均缩减为一个像素点（$1 \times 1$）。
    - _特点_：常用于 CNN 的末端，用来直接替代参数量巨大的全连接层，能极大地防止过拟合。

### 3 池化层的核心特点

1. **无参数需要训练**：池化层只有超参数（窗口大小、步长），没有可学习的权重 $w$ 和偏置 $b$。
2. **通道数（Depth）保持不变**：池化只在每个通道内部的二维平面（$H$ 和 $W$）上滑动，输入是多少通道，输出就是多少通道。
3. **输出尺寸计算公式**（与卷积类似）：
    
    $$H_{out} = \lfloor \frac{H_{in} + 2 \times \text{padding} - \text{kernel\_size}}{\text{stride}} \rfloor + 1$$

## 2. PyTorch 池化 API 详解

在主流深度学习框架 PyTorch 中，最常用的 2D 图像池化 API 主要有以下几种：

### 2.1 标准池化 API

```python
import torch.nn as nn

# 1. 最大池化 (Max Pooling)
nn.MaxPool2d(
    kernel_size=2,    # 池化窗口大小，可以是单数（2表示2x2）或元组（2,3）
    stride=2,         # 步长，默认情况下等于 kernel_size
    padding=0,        # 四周填充值
    dilation=1,       # 空洞率
    return_indices=False, # 是否返回最大值对应的索引（在反卷积/上采样网络 SegNet 中会用到）
    ceil_mode=False   # 是否用计算结果向上取整（True则保留边界不足窗口大小的部分）
)

# 2. 平均池化 (Average Pooling)
nn.AvgPool2d(
    kernel_size=2,
    stride=2,
    padding=0,
    count_include_pad=True # 计算平均值时，是否把边界填充的0也算作分母的一部分
)
```

### 2.2 自适应池化 API (强烈推荐)

普通的池化需要你根据输入动态计算 `stride` 和 `kernel_size`，而**自适应池化**只需要你指定**最终想要的输出尺寸**，框架会自动帮你计算窗口大小和步长。它非常适合处理输入分辨率不固定的网络结构。

```python
# 无论输入特征图多大，输出一律强制变为 7x7
nn.AdaptiveMaxPool2d(output_size=(7, 7))

# 全局平均池化 (GAP) 的完美实现：无论前层特征图是 32x32 还是 7x7，输出直接变成 1x1
nn.AdaptiveAvgPool2d(output_size=(1, 1))
```

## 3. 普通卷积网络结构搭建 API

搭建一个完整的 CNN，通常需要将**卷积层、激活层、池化层、展平操作和全连接层**有机地组合在一起。

### 3.1 核心搭建组件 API

- `nn.Conv2d(in_channels, out_channels, kernel_size, stride, padding)`：二维卷积层。
- `nn.ReLU()`：非线性激活层。
- `nn.Flatten()`：将多维的特征图（如 `[Batch, Channel, H, W]`）展平为二维矩阵（`[Batch, Channel * H * W]`），用于连接全连接层。
- `nn.Linear(in_features, out_features)`：全连接层（线性层）。
- `nn.Sequential()`：容器，可以将上述层按照顺序串联起来，简化前向传播代码。

### 3.2 经典 CNN 结构搭建模板实战

以下是一个标准的卷积神经网络搭建示例。我们将使用继承 `nn.Module` 的标准做法，并结合 `nn.Sequential` 来让代码结构更加清晰：

```python
import torch
import torch.nn as nn

class StandardCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(StandardCNN, self).__init__()
        
        # 使用 nn.Sequential 封装特征提取网络 (Feature Extractor)
        self.feature_extractor = nn.Sequential(
            # Layer 1: 输入 [B, 3, 32, 32] -> 输出 [B, 16, 32, 32]
            nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, stride=1, padding=1),
            nn.BatchNorm2d(16),
            nn.ReLU(),
            # 池化下采样: 输出 [B, 16, 16, 16]
            nn.MaxPool2d(kernel_size=2, stride=2),
            
            # Layer 2: 输入 [B, 16, 16, 16] -> 输出 [B, 32, 16, 16]
            nn.Conv2d(in_channels=16, out_channels=32, kernel_size=3, stride=1, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            # 池化下采样: 输出 [B, 32, 8, 8]
            nn.MaxPool2d(kernel_size=2, stride=2)
        )
        
        # 使用自适应全局平均池化，确保即使输入大小改变，送入全连接层的维度也固定
        self.global_pool = nn.AdaptiveAvgPool2d((4, 4)) # 输出 [B, 32, 4, 4]
        
        # 使用 nn.Sequential 封装分类网络 (Classifier)
        self.classifier = nn.Sequential(
            nn.Flatten(), # 展平特征图: 32 * 4 * 4 = 512
            nn.Linear(in_features=512, out_features=128),
            nn.ReLU(),
            nn.Dropout(p=0.5), # 引入 Dropout 防止过拟合
            nn.Linear(in_features=128, out_features=num_classes) # 映射到类别数
        )
        
    def forward(self, x):
        # 1. 提取特征
        x = self.feature_extractor(x)
        # 2. 全局池化
        x = self.global_pool(x)
        # 3. 分类输出
        logits = self.classifier(x)
        return logits

# --- 测试网络结构 ---
if __name__ == "__main__":
    model = StandardCNN(num_classes=10)
    # 模拟一个 Batch 大小为 4 的 RGB 32x32 图像输入
    fake_input = torch.randn(4, 3, 32, 32) 
    output = model(fake_input)
    print("输入尺寸:", fake_input.shape)
    print("输出尺寸 (Batch, Classes):", output.shape) # 应为 [4, 10]
```
