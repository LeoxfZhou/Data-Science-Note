# mAP (mean Average Precision)

在目标检测任务中，**mAP（平均精度均值）** 是评估模型好坏最核心、最综合的指标。要彻底搞懂 mAP，我们需要建立一个清晰的逻辑递进链条：**IOU $\rightarrow$ 混淆矩阵 (TP/FP/FN) $\rightarrow$ Precision/Recall $\rightarrow$ PR 曲线 $\rightarrow$ AP $\rightarrow$ mAP**。

## 一、 根基：从目标检测的特殊性谈起 (TP, FP, FN)

在普通的分类任务中，判断预测对错很简单；但在目标检测中，预测框的位置和大小很难和真实框（Ground Truth）百分之百重合。因此，我们需要引入 **交并比 (IoU)** 来量化判断“预测得对不对”。

### 1. 目标检测中的混淆矩阵定义

通常以 **$\text{IoU} = 0.5$** 作为划分对错的黄金标准阈值（注：PASCAL VOC 常用 0.5，而 COCO 数据集则建议在 0.5 到 0.95 之间采取多个不同阈值分别计算）：

- **TP (True Positive, 真正例)**：模型预测为正例（给出了预测框），且该预测框与真实框的 $\text{IoU} > 0.5$。也就是说，**模型不仅找到了目标，而且找得挺准**。
- **FP (False Positive, 假正例)**：模型预测为正例，但该预测框与真实框的 $\text{IoU} \le 0.5$（或者对同一个物体重复检测了多个框）。也就是说，**模型找错了，或者定位严重跑偏**。
- **FN (False Negative, 假负例)**：实际为正例，但模型没有预测出来。在目标检测中，**直接把“漏检的物体数目”当作 FN**。
- **TN (True Negative, 真负例)**：实际为负例，预测也为负例。在目标检测中，由于背景中可以产生无数个任意大小不包含物体的框，**TN 在实际计算中没有意义，通常不予考虑**。

## 二、 核心双子星：精度 (Precision) 与 召回率 (Recall)

利用上面得到的 TP、FP、FN，我们可以衍生出两个互相制约的指标：

### 1. 精度 (Precision) —— “找得准不准”

在模型**所有预测为正例的框**当中，真正找对的比例是多少？

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$

### 2. 召回率 (Recall) —— “找得全不全”

在全图**所有真正存在的物体**当中，模型成功捞回来的比例是多少？

$$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$

## 三、 动态演算：如何通过置信度计算 AP (Average Precision)

在实际推理时，每个预测框都自带一个**置信度分数 (Confidence Score)**。如果我们人为调高置信度阈值，模型给出的框就会变少（Precision 变高，Recall 变低）；反之，调低阈值，框变多（Recall 变高，Precision 变低）。

**AP 的本质，就是衡量模型在所有可能的置信度阈值下的整体表现。**

###  实战演练：一步步推导 AP 曲线

假设图上一共有 **3 个真实的物体标签（Total Ground Truth = 3）**。模型跑完后，输出了 3 个预测框，我们按照**置信度从高到低**进行排序，并逐一放开阈值进行动态计算：

|**动态步数**|**开启的置信度阈值**|**当前有效的预测框**|**检测结果 (IoU判定)**|**累计 TP**|**累计 FP**|**动态 Precision**|**动态 Recall**|
|---|---|---|---|---|---|---|---|
|**Step 1**|$0.9$|`predict1`|正确 (TP=1)|1|0|$\frac{1}{1} = 1.0$|$\frac{1}{3} \approx 0.33$|
|**Step 2**|$0.8$|`predict1`, `predict2`|错误 (FP=1)|1|1|$\frac{1}{2} = 0.5$|$\frac{1}{3} \approx 0.33$|
|**Step 3**|$0.7$|`predict1`, `predict2`, `predict3`|正确 (TP=2)|2|1|$\frac{2}{3} \approx 0.67$|$\frac{2}{3} \approx 0.67$|

###  PR 曲线平滑技巧与面积计算

将上表中的 (Recall, Precision) 作为坐标点画在图上，这就是 **PR 曲线**。

为了消除曲线上因为 FP 带来的局部锯齿抖动，目标检测采用“向左看齐”的单调递减平滑法：在每个“峰值点”往左画一条水平直线，直到和上一个峰值点的垂直线相交。此时，**平滑后曲线与坐标轴围成的图形面积，就是该类别的 AP 值**。

按照上文数据的曲线面积折算公式（只取recall有变化的节点，因为1/3-2/3部分，precision变成因为右侧从0.5拉到了0.67，和2/3-3/3一致，所以不取第三块）：

$$\text{AP} = \left( 1.0 \times \frac{1}{3} \right) + \left( \frac{2}{3} \times \frac{1}{3} \right) = \frac{1}{3} + \frac{2}{9} = \frac{5}{9} \approx 0.55$$

## 四、 终点：从单类别 AP 到多类别 mAP

- **AP (Average Precision)**：只用来衡量**一个单一类别**的检测好坏情况。
- **mAP (mean Average Precision)**：面对多目标检测时，把**所有类别的 AP 值全部加起来算一个数学平均值**，用以评估整个模型的综合性能。

###  数学公式

$$\text{mAP} = \frac{\sum_{k=1}^{N} \text{AP}_k}{N(\text{classes})}$$

> ** 举个栗子**：
> 
> 假设你的检测模型一共只认识两个类别：飞机和坦克。
> 
> - 经计算，飞机的 $\text{AP}_{\text{airplane}} = 0.5$
> - 坦克的 $\text{AP}_{\text{tank}} = 0.2$
> 
> 那么该模型最终的 $\text{mAP} = \frac{0.5 + 0.2}{2} = 0.35$。
