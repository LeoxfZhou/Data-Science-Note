# 📝 核心知识点：YOLO 目标检测的两块基石

在做任务前，必须理解老师这两份代码（`01_voc2yolo.py` 和 `02_手写数字...py`）在干什么。

### 1. 坐标转换的本质（VOC 格式 vs YOLO 格式）

- **VOC 格式（XML 文件）**：使用的是**绝对像素坐标**，记录的是左上角和右下角的坐标值 $[x_{min}, y_{min}, x_{max}, y_{max}]$。
- **YOLO 格式（TXT 文件）**：使用的是**相对归一化坐标**，记录的是中心点坐标、宽度和高度占整张图宽高的百分比 $[c_x, c_y, w, h]$，数值均在 $0 \sim 1$ 之间。

> **转换公式（`01_voc2yolo.py` 里的核心算法）**：
> 
> $$c_x = \frac{x_{min} + x_{max}}{2 \times \text{img\_width}}, \quad c_y = \frac{y_{min} + y_{max}}{2 \times \text{img\_height}}$$
> 
> $$w = \frac{x_{max} - x_{min}}{\text{img\_width}}, \quad h = \frac{y_{max} - y_{min}}{\text{img\_height}}$$

### 2. 目标检测数据集生成的本质（Data Synthesis）

`02_手写数字目标检测数据集生成.py` 解决的是“没有标注数据怎么办”的问题。通过编写算法（数据增强、随机旋转、随机粘贴、冲突检测），把分类数据集（MNIST 单个数字）转换成一个包含多个目标的**模拟真实场景的目标检测数据集**。这种手法在工业界（比如检测车牌、包装袋生产日期、印刷缺陷）非常常用。

### 🧱 任务一（基础关）：手写单张图的 VOC 到 YOLO 坐标转换器

**【任务目标】**：不依赖任何第三方复杂解析库，只用 Python 纯数学计算，把一个手动给定的 VOC 边框转换为 YOLO 格式。

**【任务描述】**：

假设有一张手写数字合成图，它的分辨率（宽、高）为 $W=400, H=300$。你用 LabelImg 框出了一个数字“5”，左上角像素坐标为 $(100, 50)$，右下角像素坐标为 $(200, 150)$，该物体的类别标签是 `digit_5`（对应索引为 `5`）。

请编写一个简单的 Python 函数 `voc_to_yolo_core(img_w, img_h, box)`，输入上述参数，输出 YOLO 格式的一行字符串，并打印出来。

**【解题核心思路提示】**：

1. 计算物体的绝对宽度 $w_{abs} = 200 - 100 = 100$。
2. 计算物体的绝对高度 $h_{abs} = 150 - 50 = 100$。
3. 计算中心点绝对坐标 $cx_{abs} = 100 + \frac{100}{2} = 150$。
4. 将它们分别除以 $W$ 和 $H$ 进行归一化。
5. 期望的输出格式字符串为：`5 0.375 0.3333 0.25 0.3333`。

3. **第二步（训练自己的数据集）**：将任务二中准备好的手写数字目标检测数据集（Images + Labels + data.yaml）放在源码指定位置。运行训练命令：
    
    `python train.py --img 640 --batch 16 --epochs 10 --data data.yaml --weights yolov5s.pt`

**【解题核心思路提示】**：

- 跑目标检测源码最容易遇到环境和路径问题。

- **预训练权重**：训练时加上 `--weights yolov5s.pt` 叫做**迁移学习**。这比不加权重（从零训练）收敛速度快 10 倍以上，一定要带上它。

### 🚀 任务四（地狱冲刺关）：逆向思考——自己编写代码将合成数据集“自带标注输出”

**【任务目标】**：彻底打通数据生成与目标检测的闭环。老师的作业2要求先合成图片，再用 LabelImg 手动去框 100 张图（这会点鼠标点到手酸）。**真正的目标检测高级工程师会怎么做？在生成图片的同时，直接让代码把 YOLO 格式的 TXT 标注文件自动生成出来！**

**【任务描述】**：

结合老师的 `02_手写数字目标检测数据集生成.py` 思想，编写一个进阶版脚本：

当你在黑色背景图的坐标 $(X, Y)$ 处贴上一张缩放后的数字图片时，你的代码其实是**绝对精确地知道**这个数字的边界在哪里的。请在 `paste_number_img` 函数中，每贴成功一个数字，就自动计算出该数字的 $x_{min}, y_{min}, x_{max}, y_{max}$，并立刻调用任务一的转换公式，将这一行 YOLO 格式的标注追加写入到一个与图片同名的 `.txt` 文件中。

**【解题核心思路提示】**：

1. 假设黑色背景图上随机选中的左上角粘贴位置是 $(X_{paste}, Y_{paste})$。
2. 此时被粘贴的 MNIST 数字图片经过了缩放，其当前的高和宽为 $H_{num}, W_{num}$。
3. 那么这个数字在背景图上的绝对边界框就是：
    
    - $x_{min} = X_{paste}$
    - $y_{min} = Y_{paste}$
    - $x_{max} = X_{paste} + W_{num}$
    - $y_{max} = Y_{paste} + H_{num}$
        
4. 拿到这四个值和背景图的总宽高，直接通过数学公式算出归一化的 $c_x, c_y, w, h$，用 `with open('xxx.txt', 'a')` 写入文件。
5. **做完这个任务，你将实现 0 秒人工标注，瞬间生成 10000 张完美对齐的目标检测训练集！**
