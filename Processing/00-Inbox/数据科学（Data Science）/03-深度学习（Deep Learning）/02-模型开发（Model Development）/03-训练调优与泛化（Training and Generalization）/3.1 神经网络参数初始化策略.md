# 深度学习中的参数初始化与梯度流 (Weight Initialization & Gradient Flow)

参数初始化是深度网络训练成败的决定性因素之一。不恰当的初始化会直接导致网络在训练初期就陷入瘫痪。本篇笔记将系统梳理各类参数初始化方法、背后的数学原理，以及它们如何影响网络中的**梯度流 (Gradient Flow)**。

## 1. 核心挑战：为什么权重初始化如此重要？

在深层神经网络中，前向传播和反向传播可以被视为一个**信号放大/缩小链条**。

### 1.1 梯度异常现象

- **梯度消失 (Vanishing Gradient)**：在反向传播过程中，误差梯度流经多层乘积后指数级减小，导致靠近输入层的权重几乎无法更新。
- **梯度爆炸 (Exploding Gradient)**：如果网络中的权重或其导数大于 $1$，在多层连续乘积下，梯度会呈指数级增长，导致权重更新过大、模型丧失稳定性并无法收敛。其中，深层网络中的底层（靠近输入层）由于乘积项最多，受梯度爆炸的影响往往更加剧烈。
- **收敛缓慢 (Slow Convergence)**：不合理的初始化会让网络在不佳的误差平面上缓慢前行，延长收敛所需的迭代次数。

### 1.2 初始化的终极目标

> **核心任务**：使网络在**前向传播**时，各层激活值的方差保持稳定；同时在**反向传播**时，各层梯度的方差也保持稳定。避免信号在传递过程中发生指数级的衰减（消失）或膨胀（爆炸）。

## 2. 那些年我们踩过的坑：幼稚的初始化方式

- **全 0 / 恒定常数初始化 (Zero/Constant Initialization)**：
    - _后果_：**彻底失败**。
    - _原因_：由于对称性问题（Symmetry），同一层中的所有神经元会接收到完全相同的梯度更新量。它们在更新后依然保持完全一致，这就让网络退化成了只有一个神经元的线性模型。
- **随机小高斯分布 (如 $W \sim \mathcal{N}(0, 0.01)$)**：
    - _后果_：**极易发生梯度消失**。
    - _原因_：由于权重极其微小，在前向传播中，激活值的方差会随着层数加深快速收缩至 0。反向传播时，误差信号也会在流过几层后迅速衰竭。
- **随机大高斯分布 (如 $W \sim \mathcal{N}(0, 1)$)**：
    - _后果_：**梯度饱和消失**或**梯度爆炸**。
    - _原因_：若使用 Sigmoid/Tanh 激活函数，过大的输入会使神经元直接进入饱和区（导数几乎为 0），引发严重的饱和型梯度消失；若使用 ReLU 激活函数，则会导致输出数值和梯度直接爆炸。

## 3. Xavier (Glorot) 初始化

由 Xavier Glorot 和 Yoshua Bengio 于 2010 年提出，主要用于**对称且无饱和激活函数**（如 Tanh、Sigmoid 在原点附近的线性区域）。

### 3.1 核心思想

假设网络当前层输入维度为 $n_{in}$（即 fan-in），输出维度为 $n_{out}$（即 fan-out）。Xavier 的目标是使：

1. **前向传播**时：输入和输出的方差一致 $\implies Var(W) = \frac{1}{n_{in}}$
2. **反向传播**时：输入和输出梯度的方差一致 $\implies Var(W) = \frac{1}{n_{out}}$

为了同时折中两者的需求，Xavier 取了这两者的调和平均：

$$Var(W) = \frac{2}{n_{in} + n_{out}}$$

### 3.2 实际分布公式

- **高斯（正态）分布形式**：
    
    $$W \sim \mathcal{N}\left(0, \sqrt{\frac{2}{n_{in} + n_{out}}}\right)$$
    
- **均匀分布形式**：
    
    $$W \sim U\left(-\sqrt{\frac{6}{n_{in} + n_{out}}}, \sqrt{\frac{6}{n_{in} + n_{out}}}\right)$$

### 3.3 为什么 Xavier 会在 ReLU 网络中失效？

Xavier 初始化假设激活函数的导数在 0 附近近似为 1（如线性激活）。

但 **ReLU 会强制截断所有负值**，这意味着每一层都会丢失近 $50\%$ 的信号能量：

$$Var(\text{ReLU}(x)) = \frac{1}{2} Var(x)$$

随着网络层数加深，激活值的方差会以 $0.5^{L}$ 的速度呈指数级萎缩。经过 10 层网络后，原信号的方差就仅剩 $0.5^{10} \approx 0.001$。这使得 Xavier 无法维持 ReLU 网络的梯度流动。

## 4. Kaiming (He) 初始化

由何恺明（Kaiming He）等人于 2015 年提出，专门为了解决 **ReLU 及其变体（如 Leaky ReLU）** 在深层网络中信号衰减的问题。

### 4.1 核心思想

既然 ReLU 会让方差折半，那么在初始化权重时，**直接将权重的方差翻倍（乘 2）来抵消这种减损即可**。

### 4.2 实际分布公式

- **高斯（正态）分布形式**：
    
    $$W \sim \mathcal{N}\left(0, \sqrt{\frac{2}{n_{in}}}\right)$$
    
- **均匀分布形式**：
    
    $$W \sim U\left(-\sqrt{\frac{6}{n_{in}}}, \sqrt{\frac{6}{n_{in}}}\right)$$

> **针对 Leaky ReLU 的修正**：
> 
> 如果激活函数为 Leaky ReLU（负斜率为 $\alpha$），其方差缩放因子不再是 2，公式修正为：
> 
> $$Var(W) = \frac{2}{(1 + \alpha^2) \cdot n_{in}}$$

## 5. 参数初始化方法对比“速查表”

|**初始化方法**|**理论依据公式 Var(W)**|**推荐激活函数**|**梯度流特点**|
|---|---|---|---|
|**LeCun 初始化**|$\frac{1}{n_{in}}$|Selu, Linear|在经典的简单前馈网络中保持输入端方差稳定。|
|**Xavier (Glorot)**|$\frac{2}{n_{in} + n_{out}}$|Tanh, Sigmoid|维持对称激活函数各层之间梯度和激活值的稳定。在深层 ReLU 网络中会导致梯度流逐渐枯竭。|
|**Kaiming (He)**|$\frac{2}{n_{in}}$|ReLU, Leaky ReLU|完美弥补了 ReLU 截断负信号带来的方差损失，使得深层（如 100 层以上）网络的梯度流依旧稳健。|

## 6. PyTorch 中应用初始化 API 示例

在 PyTorch 中，我们可以非常简单地在模型构建或参数定义阶段通过 `torch.nn.init` 模块应用这些初始化方法：

```Python
import torch
import torch.nn as nn

class InitDemoNet(nn.Module):
    def __init__(self):
        super(InitDemoNet, self).__init__()
        self.conv1 = nn.Conv2d(3, 64, kernel_size=3, padding=1)
        self.fc1 = nn.Linear(64 * 32 * 32, 10)
        
        # 调用自定义初始化函数
        self._initialize_weights()

    def _initialize_weights(self):
        for m in self.modules():
            if isinstance(m, nn.Conv2d):
                # 对卷积层采用 Kaiming 正态初始化（推荐配合 ReLU）
                nn.init.kaiming_normal_(m.weight, mode='fan_in', nonlinearity='relu')
                if m.bias is not None:
                    nn.init.constant_(m.bias, 0.0) # 偏置项设为 0
                    
            elif isinstance(m, nn.Linear):
                # 对全连接层采用 Xavier 均匀初始化（推荐配合 Tanh）
                nn.init.xavier_uniform_(m.weight)
                if m.bias is not None:
                    nn.init.constant_(m.bias, 0.0)
```
