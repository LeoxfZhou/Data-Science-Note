**1 加载恢复模型 (Load Model)**
* **常用方法**：
    * `model.load_state_dict(state_dict, strict=True)`：加载权重，`strict=False` 允许键值不完全匹配（用于迁移学习截断）。
    * `torch.load(f, map_location)`：读取磁盘文件，`map_location` 处理 GPU 权重加载到 CPU 上的情况。
    * *eg.*
        ```python
        model = SimpleCNN(num_classes=10).to(device) # 1. 重新实例化结构
        # 2. 读取权重（将GPU训练的权重安全加载到当前设备）
        weights = torch.load('best_model.pth', map_location=device)
        model.load_state_dict(weights)               # 3. 填入网络
        model.eval()                                 # 4. 切勿忘记评估模式！
        ```

**2 待预测样本预处理 (Inference Data Prep)**
* **核心任务**：应用基础 Transform，增加 Batch 维度。
* **常用方法**：`tensor.unsqueeze(dim)`。
    * *eg.*
        ```python
        image = Image.open('test.jpg').convert('RGB')
        # inference_transform 只包含 Resize, ToTensor, Normalize
        input_tensor = inference_transform(image)
        # input_tensor 形状为 [C, H, W]，需扩展为 [1, C, H, W]
        input_tensor = input_tensor.unsqueeze(0).to(device)
        ```

**3 样本预测与后处理 (Forward Pass & Post-processing)**
* **核心任务**：前向计算并转换 Logits。
* **常用方法**：`torch.softmax(input, dim)`, `torch.argmax(input, dim)`。
    * *eg.*
        ```python
        with torch.no_grad():
            raw_logits = model(input_tensor) # 输出 shape: [1, num_classes]

            # 多分类后处理
            probabilities = torch.softmax(raw_logits, dim=1)
            predicted_class = torch.argmax(probabilities, dim=1).item()
            confidence = probabilities[0][predicted_class].item()

        print(f"预测类别: {predicted_class}, 置信度: {confidence:.2%}")
        ```
