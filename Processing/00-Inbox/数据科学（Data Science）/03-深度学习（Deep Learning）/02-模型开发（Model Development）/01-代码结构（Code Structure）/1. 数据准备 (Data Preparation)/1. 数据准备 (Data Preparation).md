**1 数据集定义 (Dataset)**
* **核心任务**：读取磁盘上的数据，定义如何获取单个样本及标签。
* **常用方法**：继承 `torch.utils.data.Dataset`。
    * `__init__(self, data_dir, transform=None)`：初始化数据路径、读取标注文件列表、接收数据增强对象。
        * *eg.* `self.img_paths = os.listdir(data_dir)`
    * `__len__(self)`：返回数据集总大小。
        * *eg.* `return len(self.img_paths)`
    * `__getitem__(self, idx)`：读取单个数据并应用 Transform，返回 Tensor。
        * *eg.*

            ```python
            img_path = self.img_paths[idx]
            image = Image.open(img_path).convert('RGB')
            label = self.labels[idx]
            if self.transform:
                image = self.transform(image)
            return image, label
            ```

**2 数据预处理与增强 (Transforms)**
* **核心任务**：标准化、裁剪、翻转等。
* **常用方法/库**：
    * **图像 (torchvision.transforms)**
        * `transforms.Compose(transforms)`：组合多个变换。
        * `transforms.Resize(size=(H, W))`：调整图像大小。
        * `transforms.ToTensor()`：将 PIL/numpy 转换为 Tensor，并归一化到 [0, 1]。
        * `transforms.Normalize(mean, std)`：逐通道标准化。
        * *eg.*

            ```python
            train_transform = transforms.Compose([
                transforms.Resize((256, 256)),
                transforms.RandomHorizontalFlip(p=0.5), # 50%概率水平翻转
                transforms.ToTensor(),
                transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
            ])
            ```

    * **音频 (torchaudio.transforms)**
        * `torchaudio.transforms.MelSpectrogram(sample_rate, n_fft, n_mels)`：提取梅尔频谱图。
        * *eg.*

            ```python
            audio_transform = torchaudio.transforms.MelSpectrogram(
                sample_rate=16000, n_mels=128
            )
            ```

    * **第三方库 (albumentations)**：速度更快，支持对 image, mask, bboxes 同时做相同的增强。
        * *eg.*

            ```python
            import albumentations as A
            from albumentations.pytorch import ToTensorV2

            albu_transform = A.Compose([
                A.RandomCrop(width=256, height=256),
                A.HorizontalFlip(p=0.5),
                A.RandomBrightnessContrast(p=0.2),
                ToTensorV2()
            ])
            # 调用时：transformed = albu_transform(image=image_np)["image"]
            ```

**3 数据加载器组装 (DataLoader)**
* **核心任务**：批量生成 (Batching)、打乱 (Shuffle)、多线程。
* **常用方法**：
    * `torch.utils.data.DataLoader(dataset, batch_size, shuffle, num_workers, pin_memory, drop_last)`
        * `batch_size`: 每个批次的样本数（如 16, 32, 64）。
        * `shuffle`: 训练集设为 True，验证/测试集设为 False。
        * `num_workers`: 加载数据的子进程数（通常设为 CPU 核心数的 1/2 或 1/4）。
        * `pin_memory`: 设为 True 可以加速数据从 CPU 向 GPU 转移。
        * `drop_last`: 设为 True 丢弃最后数量不足一个 batch 的数据（防止 BatchNorm 报错）。
    * *eg.*

        ```python
        train_loader = DataLoader(
            train_dataset,
            batch_size=32,
            shuffle=True,
            num_workers=4,
            pin_memory=True,
            drop_last=True
        )
        ```
