### 一、 核心认知：为什么需要 CNN？

传统神经网络（全连接网络）在处理图像时，会将整个图像展平输入，导致参数量呈指数级爆炸。

CNN 的出现完美解决了这个问题，它的核心优势在于：

- **局部感知**：神经元不需要感知全局图像，只需像拿着放大镜一样扫描图像的局部区域。
    
- **参数共享**：同一个“放大镜”（卷积核）在滑动扫描整张图片时，其内部的参数是固定不变的，极大减少了模型需要学习的参数量。

### 二、 CNN 的“积木”组件 (层级结构)

CNN 本质上是通过不断堆叠以下几种“基础积木”来完成特征提取和分类任务的：

**1. 输入层 (Input Layer)**

- **作用**：接收原始数据。
    
- **关键动作**：必须进行预处理（如去均值、标准化、归一化），目的是统一数据尺度，避免网络收敛过慢。
    

**2. 卷积层 (CONV Layer)**

- **本质**：局部区域的线性组合（$W \times X + b$）。
    
- **作用**：特征提取。不仅融合局部区域的空间特征，还融合不同通道（Channel）之间的特征。
    
- **核心参数**：
    
    - **卷积核/窗口大小 (Kernel Size)**：决定局部感知的视野范围（如 3x3）。
        
    - **步长 (Stride)**：窗口每次滑动的跨度。
        
    - **填充 (Padding)**：在图像边缘补零，以控制输出尺寸并保留边缘信息。
        

**3. 激活层 (Activation Layer)**

- **作用**：引入非线性特征。如果不加激活函数，无论堆叠多少层卷积，本质上仍然是线性变换。
    
- **特点**：**绝对不改变数据的形状**，仅在原位置进行独立的非线性数学转换（如 ReLU、Sigmoid）。
    

**4. 池化层 (Pooling Layer)**

- **作用**：压缩特征图的高和宽（降维），从而大幅降低后续全连接层的计算量和参数量。
    
- **特点**：
    
    - **独立计算**：每个通道自己算自己的，不进行跨通道融合。
        
    - **固定运算，无学习参数**：通常为最大池化（Max Pooling）或平均池化（Avg Pooling）。
        
    - **去噪与特征筛选**：最大池化在反向传播时，只将梯度回传给最大值位置，久而久之能自动抑制无用噪声，凸显关键特征。
        

**5. 全连接层 (FC Layer)**

- **作用**：综合前面提取到的所有局部特征，输出全局决策（如分类的置信度）。
    
- **等价性**：当卷积核的大小完全等于输入特征图大小时，此时的卷积操作在数学意义上等价于全连接。

### 三、 数据在 CNN 中的流动规律

理解 CNN，最重要的就是理解数据张量 `(bs, c, h, w)` 在网络中是如何变化的：

|**维度简称**|**含义**|**在前向传播中的变化规律**|
|---|---|---|
|**bs (Batch Size)**|批次大小 / 样本数|**全程不变**。样本之间相互独立计算。|
|**c (Channels)**|通道数 / 特征数|**不断变化**。由定义网络时设定的“卷积核数量”决定，通常随着网络加深而增加（提取的特征维度越来越高）。|
|**h (Height)**<br><br>  <br><br>**w (Width)**|特征图的高度与宽度|**受卷积步长和池化影响**。通常在卷积和激活阶段保持不变（步长为1+填充），在经过**池化层**时被压缩（如步长为2时高宽减半）。|

### 四、 进阶：轻量级网络 MobileNet 与计算量优化

为了让 CNN 能够在手机等移动端运行，业界提出了诸如 MobileNet 的轻量级架构，其核心创新是 **深度可分离卷积**：

- **传统标准卷积**：同时进行空间和通道的特征融合。
    
- **深度可分离卷积 (两步走)**：
    
    1. **深度卷积 (Depthwise)**：只对空间进行卷积（逐通道独立过滤）。
        
    2. **逐点卷积 (Pointwise)**：用 1x1 的卷积核专门负责通道间的特征融合。
        
- **算力优化结果**：经过数学推导，其计算量与标准卷积的比值为：$\frac{1}{N} + \frac{1}{D_K^2}$。通常情况下，它能将计算量和参数量骤降至原来的约 **九分之一**。
