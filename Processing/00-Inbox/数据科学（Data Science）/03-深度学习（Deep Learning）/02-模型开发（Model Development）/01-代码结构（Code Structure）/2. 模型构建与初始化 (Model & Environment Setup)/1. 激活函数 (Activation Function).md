### 一、 激活函数的本质与作用

在深度学习网络中，卷积层和全连接层本质上都在做**线性组合**（$W \times X + b$）。

- **核心痛点**：如果网络中只有线性组合，那么无论堆叠多少层网络，其数学等效结果依然是一个简单的线性模型，无法解决复杂的现实问题。
    
- **主要作用**：激活函数相当于引入了**非线性转换**。它打破了纯线性的限制，使得神经网络能够拟合各种复杂的非线性函数，从而具备强大的“学习与表达”能力。
    

### 二、 激活函数的两大核心物理特性

根据 Gerry 老师的课堂强调，在搭建网络数据流时，必须牢记激活函数的两个“不”与“独立”：

1. **绝对不改变数据形状**：输入张量如果是 `(bs, c, h, w)`，经过激活函数处理后，输出依然是 `(bs, c, h, w)`。它不会像卷积或池化那样改变通道数或图像的高宽。
    
2. **位置独立运算**：激活函数是逐元素（Element-wise）工作的。它在特征图的每一个像素位置上独立进行非线性的数学运算，像素与像素之间互不干扰。
    

### 三、 常见的激活函数类型

#### 1. Sigmoid (S形函数)

这是早期的经典激活函数，将输入映射到 $(0, 1)$ 之间。
![[1. 激活函数 (Activation Function)-20260508094950166.png|292]]
- **公式**：$f(x) = \frac{1}{1 + e^{-x}}$
    
- **导数**：$f'(x) = f(x)(1 - f(x))$
    
- **优点**：取值范围有限，容易理解，适合作为输出层进行概率预测。
    
- **缺点**：
    
    - **梯度消失**：当 $x$ 很大或很小时，梯度趋近于 0，导致“死神经元”现象，终止梯度传递。
        
    - **非 0 中心化**：输出均大于 0，会影响权重的更新效率。
        

#### 2. Tanh (双曲正切函数)
![[1. 激活函数 (Activation Function)-20260508095016369.png|322]]
类似于 Sigmoid，但将输出压缩到 $(-1, 1)$ 之间。

- **公式**：$f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$
    
- **导数**：$f'(x) = 1 - f(x)^2$
    
- **优点**：**0 中心化**（Zero-centered），收敛速度比 Sigmoid 快。
    
- **缺点**：依然存在梯度饱和（饱和区梯度几乎为0）的问题，容易导致梯度消失。
    

#### 3. ReLU (Rectified Linear Unit，修正线性单元)
![[1. 激活函数 (Activation Function)-20260508095047927.png|283]]
目前 CNN 中最主流、默认的首选激活函数。

- **公式**：$f(x) = \max(0, x)$
    
- **导数**：$f'(x) = \begin{cases} 1, & x > 0 \\ 0, & x \le 0 \end{cases}$
    
- **优点**：
    
    - **计算极其简单**：不需要指数运算，大大提升收敛速度。
        
    - **缓解梯度消失**：在 $x > 0$ 区域梯度恒为 1，不会产生梯度饱和。
        
    - **稀疏激活性**：模拟生物神经元的单侧抑制特性，提高特征提取的准确性。
        
- **缺点**：
    
    - **死 ReLU 现象**：如果学习率设置过大，神经元可能陷入 $x \le 0$ 的区域导致再也无法激活。解决方案是采用较小的学习率。
        
    - **变种**：为了防止值过大，有时使用 $min(max(0, x), 6)$ 即 ReLU6。
        

#### 4. Leaky ReLU
![[1. 激活函数 (Activation Function)-20260508095142098.png|286]]
为了解决 ReLU 在 $x \le 0$ 时完全无梯度的问题而设计的变种。

- **公式**：$f(x) = \begin{cases} x, & x > 0 \\ \alpha x, & x \le 0 \end{cases}$ （通常 $\alpha = 0.01$）
    
- **导数**：$f'(x) = \begin{cases} 1, & x > 0 \\ \alpha, & x \le 0 \end{cases}$
    
- **优点**：给负半轴留了一点“生机”，通过修正 $\alpha x$ 尝试解决 ReLU 的死神经元问题。
    
- **实际表现**：虽然理论上有改进，但在实际大多数场景中效果提升并不明显。
    

#### 5. ELU (Exponential Linear Unit，指数线性单元)
![[1. 激活函数 (Activation Function)-20260508095204948.png|436]]
对 ReLU 负半轴进行指数级修正。

- **公式**：$f(x) = \begin{cases} x, & x > 0 \\ \alpha(e^x - 1), & x \le 0 \end{cases}$
    
- **优点**：相比 Leaky ReLU 的线性修正，指数修正让函数更加平滑，在均值接近 0 方面表现更好，鲁棒性更强。

### 四、 在网络结构中的位置与 PyTorch 落地

在搭建“网络积木”时，激活函数通常紧跟在**卷积层**（或批量归一化层 BatchNorm）之后。

在 PyTorch 实战中，通常有两种调用方式（参考截图中的代码）：

1. **函数式调用 (`torch.nn.functional`)**：
    
    - 形式：`x = F.relu(self.conv1(x))`
        
    - 场景：通常写在 `forward` 前向传播函数中，直接对中间变量进行操作。
        
2. **模块实例化 (`torch.nn`)**：
    
    - 形式：`self.relu = nn.ReLU(inplace=True)`
        
    - 场景：通常写在 `__init__` 初始化中，作为 `nn.Sequential` 模块组合（如 DepthwiseSeparableConv 块）的一部分。其中 `inplace=True` 表示直接在原内存地址上修改数据，能稍微节省内存。
        

### 五、 进阶：MobileNet 中的激活函数设计细节

结合截图资料，激活函数在轻量级网络中的应用有着极为讲究的细节：

- **MobileNet V1 的组合**：在深度可分离卷积中，深度卷积（Depthwise）和逐点卷积（Pointwise）之后都紧跟了 ReLU。
    
    - 结构：`Conv(DW) -> BN -> ReLU` 接着 `Conv(PW) -> BN -> ReLU`。
        
- **MobileNet V2 的关键优化（Linear 替换 ReLU）**：
    
    - **痛点**：ReLU 会把所有负数强行归零。由于逐点卷积（Pointwise）经常用于**降维**，在低维空间中，特征本来就少，再用 ReLU 进行暴力截断，会造成严重的**特征破坏与丢失**。
        
    - **解决方案**：在降维的逐点卷积之后，放弃使用 ReLU，改为使用 **Linear 线性激活函数**（即保持原样），以最大程度保留特征图的完整信息。
