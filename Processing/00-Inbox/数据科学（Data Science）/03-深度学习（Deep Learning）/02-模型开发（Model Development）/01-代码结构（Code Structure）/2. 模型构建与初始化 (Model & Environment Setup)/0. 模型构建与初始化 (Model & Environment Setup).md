## 3. 激活函数 API (Activation Function API)

### 一、 激活函数的本质与作用

在深度学习网络中，卷积层和全连接层本质上都在做线性组合（$W \times X + b$）。

- **核心痛点**：如果网络中只有线性组合，那么无论堆叠多少层网络，其数学等效结果依然是一个简单的线性模型，无法解决复杂的现实问题。
    
- **主要作用**：引入**非线性转换**。它打破了纯线性的限制，使得神经网络能够拟合各种复杂的非线性函数。
    

### 二、 激活函数的两大核心物理特性 (Gerry 老师重点)

1. **绝对不改变数据形状**：输入张量如果是 `(bs, c, h, w)`，经过激活函数处理后，输出依然是 `(bs, c, h, w)`。它不会改变通道数或图像的高宽。
    
2. **位置独立运算**：激活函数是逐元素（Element-wise）工作的。它在特征图的每一个像素位置上独立进行非线性的数学运算，像素之间互不干扰。
    

### 三、 常见的激活函数类型

- **Sigmoid / Tanh**：经典 S 型函数，易产生梯度消失，主要用于特定输出层。
    
- **ReLU (首选)**：$f(x) = \max(0, x)$。计算极快，缓解梯度消失，但需注意“死神经元”现象。
    
- **LeakyReLU / ELU**：针对 ReLU 负半轴的改进版，给负值留出微小梯度。
    

### 四、 代码示例 (整合进模型)


```Python
import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        
        # --- 方式A：模块实例化 (torch.nn) ---
        # 常用于 __init__ 中，配合 nn.Sequential 使用
        self.relu = nn.ReLU(inplace=True) 
        
        self.fc = nn.Linear(16 * 32 * 32, num_classes)

    def forward(self, x):
        # 执行卷积
        x = self.conv1(x)
        
        # --- 方式B：函数式调用 (torch.nn.functional) ---
        # 常用于 forward 函数中直接调用，代码更简洁
        x = F.relu(x) 
        
        # 展平与分类
        x = x.view(x.size(0), -1)
        x = self.fc(x)
        return x

model = SimpleCNN(num_classes=10).to(device)
```

### 五、 进阶：MobileNet 中的激活函数细节

- **MobileNet V2 关键优化**：在降维的逐点卷积（Pointwise）之后，改用 **Linear 线性激活**。
    
- **原因**：ReLU 会强行归零负数，在低维空间会造成严重的特征破坏。

## 4. 损失函数构造 (Loss Function)

- **常用 API 笔记**：
    
    - `nn.CrossEntropyLoss()`：**多分类首选**。内部集成了 `Softmax`，输入层不需要额外加 `Softmax`。
        
    - `nn.BCEWithLogitsLoss()`：**二分类首选**。内部集成了 `Sigmoid`。
        
    - `nn.MSELoss()`：**回归任务首选**。计算均方误差。
        

```Python
# 代码示例
criterion = nn.CrossEntropyLoss()
```

## 5. 优化器构造 (Optimizer)

- **常用 API 笔记**：
    
    - `torch.optim.Adam(params, lr, weight_decay)`：自适应学习率优化器，收敛较快。
        
    - `torch.optim.SGD(params, lr, momentum)`：随机梯度下降，配合动量使用稳定性高。
        
- **参数说明**：
    
    - `params`：通常传入 `model.parameters()`。
        
    - `weight_decay`：对应 **L2 正则化**，防止过拟合。
        

```Python
# 代码示例
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-5)
```
