### 一、 图像分类 (Image Classification)

**业务场景：** 只需要回答“图里是什么？”（比如：这是猫还是狗？这块屏幕有没有划痕？这朵花是什么品种？）。不需要知道它在图里的具体坐标。

- **ResNet (残差网络) / DenseNet**
    - **优点：** 工业界绝对的**精度基石**。层数极深但不会“学废”（得益于残差连接）。
    - **应用：** 医疗影像诊断（判断是否有肿瘤）、工业流水线质检（良品/次品分类）。
- **MobileNet / ShuffleNet**
    - **优点：** 极其轻量、速度极快，专门为手机和低端芯片设计。
    - **应用：** 手机 APP 里的活体检测、小区门禁的人脸识别打卡。

### 二、 目标检测 (Object Detection)

**业务场景：** 既要回答“是什么”，还要用方框圈出来“在哪里”（比如我们刚做的手写数字检测）。

- **YOLO 系列 (YOLOv5, v8, v10)**
    - **优点：** 天下武功，唯快不破。**实时性极强**，且精度完全够用，是目前工业界目标检测的绝对统治者。
    - **应用：** 自动驾驶中的行人/车辆避障、安防摄像头的违规入侵报警、无人机抓拍。
- **Faster R-CNN**
    - **优点：** 虽然慢，但是**极其精准**，尤其对小目标（比如远处的米粒大小的物体）非常敏感。
    - **应用：** 卫星遥感图像分析、对漏检率要求极高的绝症早筛。

### 三、 图像分割 (Image Segmentation)

**业务场景：** 画框已经不够了，需要**精确到像素级别**，描绘出物体的完美轮廓。

- **U-Net**
    - **优点：** U型结构，对数据量要求极小，几百张图就能训出好模型。
    - **应用：** 医疗领域（精确抠出细胞或器官的形状）、工业精细缺陷抠图。
- **Mask R-CNN / YOLOv8-Seg**
    - **优点：** 能够区分出哪怕重叠在一起的同一个物体（比如一堆靠在一起的苹果，能把每个苹果单独描边）。
    - **应用：** 机械臂自动抓取、自动驾驶（精确区分哪一块像素是马路，哪一块是人行道）。

### 四、 生成式 AI 与控制 (AIGC - Generative AI)

**业务场景：** 不再是“识别”现实，而是“无中生有”**创造**现实（你提到的 ControlNet 就在这里）。

- **Stable Diffusion (SD)**
    - **优点：** 目前最强大的开源文生图大模型。
    - **应用：** 游戏公司的原画生成、电商模特的自动换衣、广告海报生成。
- **ControlNet**
    - **优点：** 它是给 SD 戴上的一条“牵引绳”。SD 瞎生成怎么办？加上 ControlNet，你可以严格规定生成人物的**姿势（骨骼）**、**线稿边缘**或者**景深**。
    - **应用：** 你画一个火柴人，它严格按照火柴人的动作生成绝美的真人；或者把毛坯房的照片精准转换成精装房渲染图。

总结来说，当老板抛给你一个需求：“我要搞一个智能停车场计费系统。”

你的大脑里就会迅速走一遍选品逻辑：

1. 先用 **YOLO** 把车牌框出来。
2. 切下车牌，再用类似 **ResNet** 的思路识别上面的字符。
3. 如果要把代码塞进门口那个破旧的摄像头里，就把模型换成轻量级的 **MobileNet**。

#### 不同场景下损失函数（Loss）怎么选？

|**任务类型**|**形象比喻**|**推荐使用的损失函数**|
|---|---|---|
|**多分类** (当前任务)|单选题（如：17 种花选 1，手写数字 0-9 选 1）|`nn.CrossEntropyLoss()`|
|**二分类**|判断题（如：是猫/不是猫，欺诈交易/正常交易）|`nn.BCELoss()` 或 `nn.BCEWithLogitsLoss()`|
|**回归任务**|填空题（如：预测房价多少万、预测明天的股票价格）|`nn.MSELoss()` (均方误差) 或 `nn.L1Loss()`|
#### 不同场景下优化器（Optimizer）怎么选？

| **优化器类型**                        | **特点与适用场景**                                                             |
| -------------------------------- | ----------------------------------------------------------------------- |
| **`optim.Adam` / `optim.AdamW`** | **全能自动挡**。新手入门、快速验证想法、训练 Transformer/大模型首选。调参压力小，收敛快。                   |
| **`optim.SGD` (带 momentum)**     | **极致操控手动挡**。在经典的 CNN 图像分类（如 ResNet）要刷到打榜的极限最高精度时使用。前期慢，后期精调上限可能高于 Adam。 |
