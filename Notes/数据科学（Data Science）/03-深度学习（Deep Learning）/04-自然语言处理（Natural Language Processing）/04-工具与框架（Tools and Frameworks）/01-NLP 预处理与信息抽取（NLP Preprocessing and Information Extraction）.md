## 二、 NLP 基石：中文分词（Tokenization）技术 (Tokenization)
### 1. 为什么中文需要分词（Tokenization）？

在英文等印欧语系中，单词之间天然用空格分隔；而中文是连续的汉字串。**分词是指将连续的文本分隔成更具有语言语义学意义的“词”序列**。因为词汇是体现文本特征的最基础单元，所以在进行分类、信息抽取等任何高级任务前，第一步必须将文本转换为单词序列。

### 2. 常规分词（Tokenization）三大流派技术路线

```
                          ┌── 正向最大匹配法 (FMM)
              ┌── 规则分词├── 逆向最大匹配法 (RMM)
              │           └── 双向最大匹配法 (BM)
              │
中文分词技术 ──├── 统计分词├── n-gram 语言模型
              │           └── HMM / CRF / LSTM / BERT 序列标注模型
              │
              └── 混合分词（规则与统计相结合）
```

- **规则分词（机械匹配）**：维护一个庞大的核心词典，在切分句子时，将句子中的字符串与词表进行逐一匹配，匹配成功则切分，否则不予切分。
- **统计分词（概率模型）**：通过统计各词在海量语料中连续出现的频度来计算成词置信度，当某些字的组合频度超过设定阈值时，即认定为一个新词。
- **混合分词**：现代工业界（如 Jieba）普遍采用混合策略，即结合词典进行快速粗切分，再借助统计模型挖掘未登录词。

### 3. Jieba 分词（Tokenization）深度解密
#### ① 核心底层算法机制

Jieba 高效中文分词的秘诀在于以下双重引擎的组合：

- **已知词切分**：基于**前缀词典**实现高效的词图扫描，将句中所有可能的成词情况组合，构建出**有向无环图（DAG）**。随后采用动态规划（DP）算法查找路径，寻找基于词频分布概率最大的最大切分组合。
- **未登录词/新词识别**：对于词典中不存在的词，Jieba 自动切换为基于字粒度的序列标注模型，采用 **HMM（隐马尔可夫模型）** 配合 **Viterbi（维特比）算法** 进行动态解码预测。

#### ② 三大核心分词（Tokenization）模式对比

|**模式名称**|**激活 API 方式**|**切分特征与适用场景**|
|---|---|---|
|**精确模式**|`jieba.cut(str)`|试图将句子以最精准、最符合人类语义的方式切开。**最适合用于文本分析与特征提取**。|
|**全模式**|`jieba.cut(str, cut_all=True)`|把句子中所有可以成词的词语全部扫描出来。**速度非常快，但无法消除歧义**，存在大量冗余。|
|**搜索引擎模式**|`jieba.cut_for_search(str)`|在精确模式的基础上，**对长词进行二次细粒度切分**。能够有效提高召回率，**专用于搜索引擎构建倒排索引**。|

#### ③ 基础工程能力矩阵

1. **分词**：前缀字典高效匹配 + HMM 维特比新词发现。
2. **自定义词典**：支持灵活添加领域专有名词，强行干预分词倾向。
3. **关键词抽取**：内置基于统计的 **TF-IDF** 算法和基于图排序的 **TextRank** 算法。
4. **词性标注**：支持输出词汇属性，同样基于 HMM 与 Viterbi 算法实现。
5. **并行分词**：利用多进程加速（_注：当前原生版本不支持 Windows 系统_）。

## 三、 词性标注（Part-of-Speech Tagging, POS） (Part-of-Speech Tagging, POS)

- **定义**：词性是词汇的基本语法属性。词性标注是指在给定的句子上下文中，判定并判定每个词的语法范畴（如名词 $n$、动词 $v$、人名 $nr$），将其确定并打上特定标签的过程。
- **中文词性特征与传统做法**：
    - 在中文里，一个词通常较为固定，仅具备 1~2 个词性，且其中某个主要词性的使用频率具有压倒性优势。
    - 因此，最简单的基线（Baseline）方法是**直接从语料库中统计高频词性作为该词的默认标注**。
- **主流学术/工业界手段**：为了解决多音多义及上下文歧义问题，当前普遍将词性标注视作**序列标注问题**，采用 **HMM**、**CRF（条件随机场）** 以及深度学习序列模型联合求解。

## 四、 命名实体识别（Named Entity Recognition, NER） (Named Entity Recognition, NER)
### 1. NER 的核心内涵与挑战

命名实体识别的核心是从非结构化文本中抽取出具有特定业务意义的实体专有名词（例如人名、地名、机构名、时间、专有名词、货币等）。它通常包含两个核心步骤：

1. **实体边界识别**：确定这个实体从哪个字开始，到哪个字结束。
2. **确定实体类别**：判定该边界内的实体究竟属于人名（PER）、地名（LOC）还是机构名（ORG）等。
- **技术演进**：传统方法采用基于规则/正则表达式的匹配；现代统计学及深度学习流派则全面拥抱 **CRF、HMM、LSTM 以及 Transformer 系列预训练模型** 进行端到端序列标注。

### 2. 现代 NER 两大主流标注方法体系（BIO vs BIOES）

在训练实体识别序列模型时，我们需要将文本转化为逐字的标签序列。主流有以下两种设计范式：

#### ① BIO 标注法（经典三标签体系）

- **`B-xxx` (Begin)**：代表该字是 `xxx` 类命名实体的**起始字**。
- **`I-xxx` (Inside)**：代表该字处于 `xxx` 类命名实体的**内部**。
- **`O` (Outside)**：代表该字**不属于任何实体**。

#### ② BIOES 标注法（精细化五标签体系）

为了给模型提供更强的结构约束，引入了结尾与单字状态：

- **`B-xxx` (Begin)**：代表该字是 `xxx` 类命名实体的**起始字**。
- **`I-xxx` (Inside)**：代表该字处于 `xxx` 类命名实体的**内部**。
- **`E-xxx` (End)**：代表该字是 `xxx` 类命名实体的**结尾字**。
- **`S-xxx` (Single)**：代表该字**单独构成**一个 `xxx` 类的命名实体。
- **`O` (Outside)**：代表该字**不属于任何实体**。

## 五、 关系抽取 (Relation Extraction)

关系抽取通常是信息抽取（IE）流水线中紧跟在命名实体识别（NER）之后的具体应用下游任务。它在工业界落地的两个主要细分方向如下：

- **细分方向 A：关系抽取（二分类视角）**
    - **任务定义**：从给定的句子中判定指定的两个实体（Entity 1 & Entity 2）之间是否存在某种特定的预设关系。这在底层可以抽象为一个纯粹的**二分类问题**（即：有关系 vs 无关系）。
- **细分方向 B：关系分类（多分类视角）**
    - **任务定义**：负责直接判定句子中两个实体具体属于哪一种关系类型（其标签集合中通常会包含一个“无关系（NA）”的类别标签）。这在底层是一个标准的**多分类问题**。

> 💡 **行业共识**：在实际工程学术交流和项目研发中，**我们通常所说的“关系抽取”在绝大多数情况下指的都是“关系分类”**。

### 典型三元组构建实例

- **原始非结构化文本**：

    > “周星驰，1962年6月22日生于香港，祖籍浙江宁波。”

- **通过 NER + 关系分类后构建的知识图谱三元组（Triplets）结果**：
    1. `(周星驰) ──[出生日期]──> (1962年6月22日)`
    2. `(周星驰) ──[出生地]────> (香港)`
    3. `(周星驰) ──[祖籍]──────> (浙江宁波)`

## 文本处理的基本方法
### 1 什么是分词（Tokenization）

- 分词就是将连续的字序列按照一定的规范重新组合成词序列的过程。在英文的行文中，单词之间是以空格作为自然分界符的，而中文只是字、句和段能通过明显的分界符来简单划界，唯独词没有一个形式上的分界符。分词过程就是找到这样分界符的过程.
- 举个例子:

```text
传智教育是一家上市公司，旗下有黑马程序员品牌。我是在黑马这里学习人工智能

['传智', '教育', '是', '一家', '上市公司', '，', '旗下', '有', '黑马', '程序员', '品牌', '。', '我', '是', '在', '黑马', '这里', '学习', '人工智能']
```

- 分词的作用:
  - 词作为语言语义理解的最小单元, 是人类理解文本语言的基础. 因此也是AI解决NLP领域高阶任务, 如自动问答, 机器翻译, 文本生成的重要基础环节.
- 流行中文分词工具jieba:
  - 愿景: “结巴”中文分词, 做最好的 Python 中文分词组件.
- jieba的特性:
  - 支持多种分词模式
    - 精确模式
    - 全模式
    - 搜索引擎模式
  - 支持中文繁体分词
  - 支持用户自定义词典
- jieba的安装:

```bash
pip install jieba
```

- jieba的使用:

> - 精确模式分词:
> - 试图将句子最精确地切开，适合文本分析.

```text
import jieba
content = "传智教育是一家上市公司，旗下有黑马程序员品牌。我是在黑马这里学习人工智能"
# 精确模型：试图将句子最精确地切开，适合文本分析。也属于默认模式
jieba.cut(content, cut_all=False)  # cut_all默认为False

# 将返回一个生成器对象
<generator object Tokenizer.cut at 0x7f8d9053e650>

# 若需直接返回列表内容, 使用jieba.lcut即可
jieba.lcut(content, cut_all=False)
['传智', '教育', '是', '一家', '上市公司', '，', '旗下', '有', '黑马', '程序员', '品牌', '。', '我', '是', '在', '黑马', '这里', '学习', '人工智能']
```

> - 全模式分词:
> - 把句子中所有的可以成词的词语都扫描出来, 速度非常快，但是不能消除歧义。

```text
# 若需直接返回列表内容, 使用jieba.lcut即可
jieba.lcut(content, cut_all=True)

['传', '智', '教育', '是', '一家', '上市', '上市公司', '公司', '', '', '旗下', '下有', '黑马', '程序', '程序员', '品牌', '', '', '我', '是', '在', '黑马', '这里', '学习', '人工', '人工智能', '智能']

# 注意1：人工智能全模型分成三个词
# 注意2：逗号和句号也给分成了词
```

> - 搜索引擎模式分词:
> - 在精确模式的基础上，对长词再次切分，提高召回率，适合用于搜索引擎分词。

```text
import jieba
content = "传智教育是一家上市公司，旗下有黑马程序员品牌。我是在黑马这里学习人工智能"
jieba.cut_for_search(content)

# 将返回一个生成器对象
<generator object Tokenizer.cut_for_search at 0x7f8d90e5a550>

# 若需直接返回列表内容, 使用jieba.lcut_for_search即可
jieba.lcut_for_search(content)
['传智', '教育', '是', '一家', '上市', '公司', '上市公司', '，', '旗下', '有', '黑马', '程序', '程序员', '品牌', '。', '我', '是', '在', '黑马', '这里', '学习', '人工', '智能', '人工智能']

# 对'无线电'等较长词汇都进行了再次分词.
```

> - 中文繁体分词:
> - 针对中国香港, 台湾地区的繁体文本进行分词。

```python
import jieba
content = "煩惱即是菩提，我暫且不提"
jieba.lcut(content)
['煩惱', '即', '是', '菩提', '，', '我', '暫且', '不', '提']
```

> - 使用用户自定义词典:
> - 添加自定义词典后, jieba能够准确识别词典中出现的词汇，提升整体的识别准确率。
> - 词典格式: 每一行分三部分：词语、词频（可省略）、词性（可省略），用空格隔开，顺序不可颠倒。
> - 词典样式如下, 具体词性含义请参照 7 jieba词性对照表 , 将该词典存为userdict.txt, 方便之后加载使用。

```text
# 格式：word1 freq1 word_type1
```

### 2 什么是命名实体识别（Named Entity Recognition, NER）

- 命名实体: 通常我们将人名, 地名, 机构名等专有名词统称命名实体. 如: 周杰伦, 黑山县, 孔子学院, 24辊方钢矫直机.
- 顾名思义, 命名实体识别(Named Entity Recognition，简称NER)就是识别出一段文本中可能存在的命名实体.
- 举个例子:

```text
鲁迅, 浙江绍兴人, 五四新文化运动的重要参与者, 代表作朝花夕拾.

==>

鲁迅(人名) / 浙江绍兴(地名)人 / 五四新文化运动(专有名词) / 重要参与者 / 代表作 / 朝花夕拾(专有名词)
```

- 命名实体识别的作用:
  - 同词汇一样, 命名实体也是人类理解文本的基础单元, 因此也是AI解决NLP领域高阶任务的重要基础环节.

### 3 什么是词性标注（Part-of-Speech Tagging, POS）

- 词性: 语言中对词的一种分类方法，以语法特征为主要依据、兼顾词汇意义对词进行划分的结果, 常见的词性有14种, 如: 名词, 动词, 形容词等.
- 顾名思义, 词性标注(Part-Of-Speech tagging, 简称POS)就是标注出一段文本中每个词汇的词性.
- 举个例子:

```text
我爱自然语言处理

==>

我/rr, 爱/v, 自然语言/n, 处理/vn

rr: 人称代词
v: 动词
n: 名词
vn: 动名词
```

- 词性标注的作用:
  - 词性标注以分词为基础, 是对文本语言的另一个角度的理解, 因此也常常成为AI解决NLP领域高阶任务的重要基础环节.
- 使用jieba进行中文词性标注:

```python
import jieba.posseg as pseg
pseg.lcut("我爱北京天安门")
[pair('我', 'r'), pair('爱', 'v'), pair('北京', 'ns'), pair('天安门', 'ns')]

# 结果返回一个装有pair元组的列表, 每个pair元组中分别是词汇及其对应的词性, 具体词性含义请参照[附录: jieba词性对照表]()
```
