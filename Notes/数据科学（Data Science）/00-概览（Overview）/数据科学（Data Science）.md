# 数据科学与深度学习学习路径

> [!summary] 这篇笔记的作用
> 这是一张“学习地图”，用于决定先学什么、学到什么程度、用什么项目验收。
> 它不是课程目录，也不要求把所有算法和框架学完。

## 1. 总体路线

```text
Python 与数据处理
        ↓
必要数学基础
        ↓
机器学习与实验方法
        ↓
深度学习原理 + PyTorch
        ↓
选择一条主线：计算机视觉（CV）或自然语言处理（NLP/LLM）
        ↓
工程化、部署与完整项目
        ↓
根据岗位要求选修 GNN、强化学习、生成模型等专题
```

建议先完成共同基础，再从 CV 和 NLP/LLM 中选择一条主线。另一条只需要了解基本概念，避免同时铺开造成“每样都看过，但没有完整项目”。

> [!important] 学习原则
> - 以一个主要框架为主：优先 PyTorch，不同时系统学习 PyTorch 和 TensorFlow。
> - 先建立可复现的 baseline，再学习复杂模型。
> - 每学一个模块都要完成“训练、评估、误差分析、改进、部署”中的至少三项。
> - 不以看完多少课程作为完成标准，以能否独立解释、实现和排错作为标准。

## 2. 需要掌握的知识结构

### 2.1 Python 与数据处理

必须掌握：

- Python 基础语法、函数、类、异常处理、模块和包。
- NumPy：数组形状、索引、广播、向量化和矩阵运算。
- Pandas：读取数据、缺失值、分组聚合、连接和基础特征处理。
- Matplotlib：训练曲线、数据分布、混淆矩阵和误差样本可视化。
- 虚拟环境、依赖文件、相对路径与基础 Git 操作。

- [ ] 能保存实验配置、模型结果和可视化图表。

### 2.2 数学基础

只学习能帮助理解模型和排错的部分，不需要先学完整套高等数学再开始写代码。

| 主题 | 必须理解的内容 | 用途 |
|---|---|---|
| 线性代数 | 向量、矩阵、张量、矩阵乘法、转置、范数 | 理解全连接层、卷积和注意力 |
| 微积分 | 导数、偏导数、梯度、链式法则 | 理解反向传播和梯度下降 |
| 概率统计 | 条件概率、期望、方差、常见分布、最大似然 | 理解损失函数、预测概率和不确定性 |
| 优化 | SGD、Momentum、Adam、学习率 | 理解参数如何更新及训练为什么不稳定 |

可后学：特征值分解、SVD、凸优化证明、复杂概率图模型。遇到具体模型需要时再补。

### 2.3 机器学习基础

算法本身只是一部分，更重要的是建立正确的实验方法。

必须掌握：

- 监督学习与无监督学习的区别。
- 线性回归、逻辑回归、决策树、随机森林和一种梯度提升树。
- 训练集、验证集、测试集的职责。
- 交叉验证、超参数搜索和数据泄漏。
- 缺失值、类别特征、数值标准化、类别不平衡。
- 分类指标：Precision、Recall、F1、ROC-AUC、PR-AUC。
- 回归指标：MAE、MSE、RMSE、$R^2$。
- 聚类和降维只需掌握 K-Means 与 PCA 的基本思想和适用场景。

阶段项目：选择一个表格数据集，完成数据分析、简单 baseline、树模型、交叉验证和误差分析。

完成标准：

- [ ] 能根据业务错误成本选择评价指标。
- [ ] 能识别常见数据泄漏。
- [ ] 能比较简单模型与复杂模型，而不是只汇报最高分。

## 3. 深度学习共同基础

### 3.1 神经网络原理

- Batch、Epoch、Iteration 的区别。
- 欠拟合、过拟合、正则化、Dropout、数据增强和早停。
- 权重初始化、Batch Normalization、残差连接。
- 梯度消失、梯度爆炸、学习率过大或过小的表现。

## 4. 主线 A：计算机视觉（CV）

如果目标是图像分类、目标检测、分割、OCR、视频分析或视觉工程岗位，选择这条主线。

### 4.1 图像处理与 CNN

学习顺序：

1. 图像表示、颜色空间、缩放、裁剪和归一化。
2. 卷积、步长、Padding、感受野和池化。
3. LeNet、AlexNet、VGG 用于理解发展过程。
4. ResNet 必须深入理解；其他骨干网络按需了解。
5. 迁移学习、冻结参数和微调。

OpenCV 只需掌握读取、颜色转换、几何变换、阈值、滤波、边缘和轮廓；不用把所有传统算子逐个学完。

### 4.2 目标检测与分割

目标检测需要掌握：

- Bounding Box、IoU、Precision、Recall、mAP。
- Anchor、NMS、一阶段与两阶段检测器的区别。
- 会使用一个现代检测框架完成训练、验证、预测和导出。
- 不需要从 YOLO V1 到每个版本逐一复现；先掌握共同原理，再使用当前项目需要的版本。

图像分割需要掌握：

- 语义分割与实例分割的区别。
- Dice、IoU 等评价指标。
- U-Net 的编码器、解码器和跳跃连接。

## 5. 主线 B：自然语言处理与大模型（NLP/LLM）

如果目标是文本分类、信息抽取、搜索、RAG、大模型应用或 Agent 工程，选择这条主线。

### 5.1 NLP 基础与 Transformer

学习顺序：

1. 文本清洗、分词、词表、Token ID、Padding 和 Attention Mask。
2. TF-IDF 和词向量：理解传统 baseline，不必投入过多时间。
3. RNN、LSTM、GRU：理解序列建模和局限，不必把它们作为现代 NLP 主力。
4. Attention、Self-Attention、位置编码和 Transformer。
5. Encoder-only、Decoder-only、Encoder-Decoder 的任务差异。
6. 使用预训练模型完成推理、微调和评估。

对应笔记：

### 5.2 大模型应用

按以下顺序学习，避免一开始就被框架封装遮住底层过程：

1. 直接调用模型 API 或 Hugging Face 模型，理解输入、输出和 Token。
2. 提示词、结构化输出、工具调用和错误处理。
3. Embedding、向量检索、召回与重排。
4. RAG 的切分、索引、检索、生成和评估。
5. 只有当普通工作流无法解决问题时，再使用 Agent 或多智能体。
6. LangChain、LangGraph、Dify 是实现工具，不是需要优先掌握的理论。

需要补充的工程知识：

- 上下文窗口、Token 成本、延迟和并发。
- Prompt Injection、敏感信息、权限隔离和输出校验。
- 幻觉、引用准确率、检索命中率与端到端任务成功率。
- 微调与 RAG 的适用边界；不要把微调当作给模型添加实时知识的方法。

推荐项目：

- 入门：使用预训练模型完成文本分类并分析混淆类别。
- 主项目：带引用来源的本地文档 RAG，并建立一组固定评测问题。
- 综合项目：包含检索、结构化输出、工具调用、日志和失败降级的业务助手。

## 6. 工程化与部署

无论选择 CV 还是 NLP，这部分都必须学习。

- 项目结构：数据、配置、训练、评估、推理和服务代码分离。
- 可复现：固定随机种子、记录依赖、配置和模型版本。
- 测试：至少为数据处理、模型输入输出和服务接口编写测试。
- 性能：Batch 推理、CPU/GPU 选择、显存、吞吐量和延迟。
- 部署：FastAPI、模型导出、容器化和基础监控。
- 模型迭代：数据版本、错误样本回流、重新训练和回滚。

## 7. 推荐学习节奏

以下时间按每周约 10–15 小时估算；基础不同可以伸缩，不建议压缩成“三天学完数学”或“七天学完机器学习”。

| 阶段 | 建议时间 | 必须产出 |
|---|---:|---|
| Python、NumPy、Pandas | 2–3 周 | 一个数据清洗与可视化 Notebook |
| 数学与机器学习 | 3–5 周 | 一个带 baseline、交叉验证和误差分析的表格项目 |
| 深度学习与 PyTorch | 4–6 周 | 独立训练循环、最佳模型保存、推理脚本 |
| CV 或 NLP 主线 | 6–10 周 | 一个完整领域项目 |
| 工程化与部署 | 3–5 周 | API、测试、配置、README 和可复现环境 |
| 综合项目与面试复盘 | 2–4 周 | 可演示项目、技术说明和问题复盘 |

学习循环建议：

```text
理解概念 → 跑通最小示例 → 自己重写 → 改一个变量做实验
→ 记录结果 → 分析失败案例 → 整理成笔记 → 应用到项目
```

## 8. 暂时删除或降级为选修的内容

以下内容不是没有价值，而是不应该同时放在入门主线上：

- TensorFlow 全套课程：除非目标岗位或现有项目明确要求，否则只保留查阅能力。
- 从 LeNet 到所有 CNN 骨干逐一复现：深入掌握 ResNet，其余理解关键创新即可。
- 从 YOLO V1 到所有版本逐一实现：学习检测共同原理，项目使用一个合适版本。
- GAN、扩散模型、强化学习、GNN：完成主线后再根据目标岗位选择。
- 大量 LangChain、Dify、LangGraph API：先掌握模型、检索、评估和工作流原理。
- 从零预训练大语言模型：个人学习阶段优先使用预训练模型、微调和 RAG。
- 罗列大量“应用场景”：只保留能转化为完整项目的场景。
